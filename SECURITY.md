# Coursework data and execution boundaries

The portable evidence package contains code, aggregate results, anonymized score clusters and documentation. Medical images, annotations, checkpoints, credentials and raw personal chat transcripts are excluded. Retrieval paths are configurable and no API key is required.

Run the standard-library smoke before exploring GPU workflows. It reads bundled data only and does not call the network. Original archive paths must be treated as read-only; training or report runners that write into a run directory are not the course smoke.

The source bundle is imported code with preserved identity. Inspect it before executing it. The packaged numerical checker validates its content hash without extracting or running it. Historical full tests may use temporary files; run them only in an isolated extracted copy.

Current task egress: public paper/repository browsing; code and numeric summaries returned to Codex. Raw medical arrays used for local checking were not sent to an external API by these scripts. Historical data egress is not fully reconstructed. User-reported teacher confirmation and Codex-executed technical checks are separately identified in AI_USAGE.md and release_status.md.

Pre-submission checks must scan the selected release files for credentials and confirm license/data permissions. A pattern scan is a limited check and does not certify the absence of every secret. Record the actual check and review rather than marking a blanket compliance pass.
