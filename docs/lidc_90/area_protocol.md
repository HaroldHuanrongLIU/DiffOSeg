# Training-only area estimation experiment

The v9 inner oracle using each true rater area was a diagnostic only. This experiment must estimate area using a single raw CT and a guide derived from that image at prediction. Generate perturbed guides from inner-training masks only, deliberately varying guide rater, position, smooth spatial error, erosion and dilation. Extract registered-CT inner/shell intensity quantiles, geometric descriptors, and distributions of inward-normal intensity and edge location. Fit a fixed ExtraTrees multioutput estimator of each rater's equivalent-radius correction using training patients. Use multiple image-predicted guides at validation to reduce dependence on an arbitrary guide threshold. Correct a predicted mask by selecting pixels from its probability ranking at the estimated area. Calibrate only a bounded shrinkage and rank bias on library patients; always show the unmodified result and held-check area RMSE. Freeze before seeing any new outer scores. A ground-truth-derived guide or true area at inference is forbidden. Fixed single-slice four-fold target is 0.90000 aligned Dice.
