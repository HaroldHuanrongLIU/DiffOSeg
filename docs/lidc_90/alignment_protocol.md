# Train-fold registration and four-rater area calibration, single CT

Before v10 outer predictions, the native local model had weak inner performance. An inner-only diagnostic found that oracle per-rank area selection would increase v9 Dice to about 0.916, while oracle translation alone provided much less relief. These are inaccessible diagnostics, never test inputs. The training image contrast across inner/outer rings of the middle-vote mask peaked after translating CT by (-1,-1) native pixels in fold-0 training data. Test whether learning the CT-to-contour coordinate convention *before* spatial augmentation improves generalization. The shift is estimated using fitting cases only, with no per-test-label calibration. Retain the original masks, scoring, patient folds, v9 consensus and whole test cohort.

## Fit

Select the integer CT shift (dx,dy) from [-2,2]^2 maximizing the mean training-case normalized inner-minus-outer rim contrast. Use separate inner and outer-training estimates. Store the entire score surface. Freeze each estimate before model fitting. Compare a matched-budget model with shift (0,0) on the same inner fold. Use a Cartesian U-Net initialized from that fold's matching v1 preference checkpoint; supervise all four aligned rank masks, signed distances and cumulative vote supports. Rotate/reflect the corrected pair about the nominal crop landmark; use slight center jitter, broad field-of-view jitter and small intensity perturbations. Recenter eccentric cases using their training landmark only during fitting. At deployment use only the single unmodified CT with the fitted global registration, a fixed crop origin and/or the image-derived native locator. A detector-predicted shift is used only outside a center dead zone. Target 6000 updates, batch 20, AdamW, final EMA. Score through native coordinates with fixed multiscale dihedral predictions. Preserve the failed v10 smoke and inner records; never label them outer results.

## Check and scope

Choose a blend with frozen v9 (0 to 1 in quarters), CT-only centering mode and at most a weak common centroid tilt on the inner calibration patients. Evaluate on the disjoint inner check patients. Report stand-alone and ensemble results, not just the best setting on fit patients. Full/outer runs are separate from the inner gate. No external patient labels, alpha or neighboring slice as inference features. A success claim requires the unrounded four-fold equal mean aligned preference Dice >=0.900000 on the original 1609 slices. Report failure and gap otherwise.
