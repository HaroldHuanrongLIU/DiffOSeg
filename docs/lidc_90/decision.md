# Lock of preference-only comparison

Three variants share trained single-image inputs and original native masks. Base is the registered full-field branch using each fold's original blend/centroid lock. Zoom mixes this calibrated full-field logit with the registered native-supervised local logit, tapering the new branch at its field edge. Fit one fold-local weight in {0,.25,.5,.75,1} on library patients. Area uses these zoom scores and the trained CT-only radiomics estimator. Correct the guide-estimated equivalent radius with half of its median calibration residual by rank; select a common bounded shrinkage strength {0,.25,.5,.75,1} by library Dice. Apply the same rule to check patients. No guide in an inference path is obtained from a target mask; offsets during training and training-only anatomy diagnostics are documented separately.

After all four checks are available, first select Zoom over Base only when it improves the averaged preference Dice by at least 0.00015 and in at least two folds. Then select Area over the chosen variant by the same rule. Require selected mean inner check Dice >=0.90000 and positive paired change versus v9 before launching the one locked comparison. Evaluate all defined arms as controls, but do not substitute a control after test scoring. The complete four-fold held-out point estimate, without rounding, determines whether the goal is met. Preserve v9 population masks. Report rank/size and localization diagnostics separately.
