# LIDC v4: count-consistent rater decoding with shared localization correction

Direct comparator: first sealed DiffOSeg-v3 predictions, summary SHA-256 27ca97941a8a2cca095358bf6d365559c67f90e3210b436c01be6851a1a6076c. Preserve the original E11 and v3 outputs. This cohort and previous v3 results have already been used. Lock v4 before outer inference; the study is a within-cohort replication with a new method, not an external clinical evaluation.

## Model and input

A single 128x128 CT patch, the matching original diffusion-derived v1 banks and frozen v1/v3 Cartesian models suffice at inference. No masks, patient identifiers, adjacent slices or cross-fold models are inference features. The four ranks are simulated area preferences. Retain K=10,30,50 with no borrowing across prefixes.

On each pixel enumerate the 16 four-bit label vectors a. Let L_i be the calibrated v3 preference log odds, C=sum_i a_i, and P_R(a) proportional to exp(sum_i a_i L_i). Form a count law P_V(C) by adjacent differences of sorted, calibrated cumulative vote probabilities including the end points 1 and 0. Define Q(C)=(1-g) P_V(C)+g P_R(C). Decode Q(a)=Q(C) P_R(a|C) by exact normalization within each of the five count strata. Return individual marginals q_i and cumulative supports S_j for C>=j. This enforces sum_i q_i=sum_j S_j. Fit four expert logit offsets, four support offsets, one temperature for each group, and a mixing coefficient g. The location module measures the centroid of the image-predicted middle vote supports. It translates all continuous logit maps jointly by alpha*(m-c)*exp(-||m-c||²/18). Estimate m as the coordinate-wise median of true middle-support centroids on that fold's inner training patients. Fixed bounds limit the deformation of eccentric lesions. Learn alpha together with the calibration variables; the deep models remain frozen. Optimize per-mask soft Dice for the four experts and four cumulative supports plus weak regularization, with patient-balanced minibatches and a fixed update budget. Calibration is independent per fold.

To generate a bank, retain v3's locked soft/hard mix and transport strength and compute the target using the calibrated S_j. Assign each original draw to a size quartile inferred from the draw areas within its prefix. Blend its per-pixel signed-distance percentile (80%) with its quartile's decoded preference relative to the mean of the four log odds (20%, logistic). Sort these scores to fill the target number of foreground draws. For the preference task use the v3 90/10 signed-distance blend with the same frozen v1 preference. Report three component removals before looking at v4 outer scores: location only; joint decoder without location; full model without the new draw ordering. Disable components at inference using the same fitted fold parameters. This measures contributions inside the fitted system.

## Data separation, gate and evidence

The model uses inner-trained v3 networks to produce predictions for v2's library and selection patient halves. Fit the small layer only on library patients; the selection half is a check set and does not choose its weights. Those patients were used historically for the frozen v3 parameters. For selection use v2's previously frozen inner surrogate draw bank; original E11 checkpoints saw these patients and cannot provide a clean inner comparator. At outer inference substitute the real frozen diffusion-derived v1 bank, with the same decoding rule. Never fit on outer data. An engineering test must verify exact marginal consistency, no correction away from support, exact per-pixel sample counts and prefix isolation. Before outer inference require improvement in all three fold-equal inner point estimates vs the same v3 surrogate. Archive the check even if it fails. Do not adapt to v4 outer scores. Freeze all four accepted parameter records, then seal all four predicted banks before scoring. Final success requires lower GED@50, higher Dice_soft@50 and higher preference Dice_mean than v3 across the identical four outer folds. Report secondary metrics, per-fold direction, ablations and paired percentile intervals from 5000 patient-cluster bootstraps stratified by fold, seed 212903. Keep original outputs on Lakers; synchronize only study source to E11/N21.

The count factor is an instance of a cardinality potential. This implementation uses exhaustive inference for four binary labels. [Tarlow et al., UAI 2012](https://proceedings.mlr.press/r10/tarlow12a.html).
