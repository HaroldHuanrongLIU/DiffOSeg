## 可实现的方法

1. **对同一像素联合建模。** 输入一张结节 CT 图块。冻结 v1/v3 网络，取得四个面积等级的偏好 logit，以及至少获得一、二、三、四票的四个 logit。在每折的内层训练患者上估计中间两层票数掩膜质心的中位数。推理时根据图像预测的质心与这个位置的差，对八张连续 logit 图施加相同的亚像素平移。偏心较大时按距离衰减，所有位置参数均在外层推理前固定。
2. **把两套预测放到同一概率模型。** 对一个像素枚举四个二值判断的 16 种组合。记组合为 $a$，票数为 $c=|a|$。用偏好 logit 得到 $P_R(a)$，用校准后累计票数概率的相邻差得到 $P_V(c)$。设 $Q(c)=(1-g)P_V(c)+gP_R(c)$，并计算 $Q(a)=Q(c)P_R(a\mid c)$。从同一个 $Q$ 求出四个面积等级的前景概率和四个累计支持概率。这里有一个可检验的恒等式：四个偏好概率之和等于四个累计支持概率之和。面积等级代表模拟偏好，并不追踪真实医生身份。
3. **以最终采样分布训练。** 单看四位标注者的边际概率不能确定一组空间一致的分割样本。为预测新的分割样本，用第二层把累计支持转换为目标前景频率 $f$。它学习逐级温度和偏置、软硬投票比例、以及与原有扩散频率的融合权重。在每个像素为 K 个样本分配 $\lfloor Kf+0.5\rfloor$ 个前景名额，按扩散有符号距离百分位与对应面积等级偏好的 80/20 组合排序填入。每个 K 仅用自己的样本前缀。偏好分割沿用 v3 的 90/10 边界融合。
4. **分开拟合两个小模块。** 联合解码和位置校正共 12 个可训练标量，用四张偏好掩膜和四个累计票数掩膜的软重叠损失拟合。频率读出层再增加 10 个标量，最小化 $\mathrm{GED}_{50}+3(1-\mathrm{Dice}_{soft,50})$。能量项就是原始 IoU 经验 V 统计量；前向用实际离散掩膜，反向用样本百分位附近的 sigmoid 提供近似梯度。两个模块均只在本折校准患者上训练，各 320 步，按患者均衡抽样。原有分割骨干冻结，每折另保存两个位置参考坐标。四个标注者可直接精确枚举；计数势的一般背景见 [Tarlow 等，UAI 2012](https://proceedings.mlr.press/r10/tarlow12a.html)。

## 开发过程与隔离

首版只训练联合解码层。内层 GED 比 v3 替代对照高 0.003270，未获准进入外层测试。加入能量距离训练后，四折在各自的内层检查患者上均同时改善三个指标。折等权变化为 GED −0.006944，Dice_soft +0.194 个百分点，偏好 Dice +0.151 个百分点。首版失败记录和修订方案均早于正式外层推理。[首版协议](protocol.md) · [分布训练协议](energy_protocol.md)

每折用仅在内层训练患者拟合的旧模型生成校准输入，校准集和检查集各自互斥。构建校准病例的替代采样库时，排除该患者的全部形状模板。检查集在前序研究中曾参与 v3 的参数选择，也用于本轮方法开发。内层使用 v2 图像分支生成的替代样本；外层使用真实 v1 扩散样本。四份最终参数在第一份外层预测前锁定，四折预测均封存后才进行逐例评分。证据属于同一居中 LIDC 队列的跨轮复评；未验证新患者队列或其他预处理流程。

## 消融

除 v3 外，表内各控制使用同一批拟合参数并在推理时禁用相应部件。未按外层分数更换正式候选。表内控制诊断该系统中部件的作用，不等同于为每种控制重新训练。

| 版本 | GED@50 ↓ | Dice_soft@50 ↑ (%) | 偏好 Dice ↑ (%) |
|---|---:|---:|---:|
| 完整 v4 | 0.104515 | 90.790 | 89.146 |
| 只做共同位置校正 | 0.107806 | 90.692 | 89.144 |
| 移除位置校正 | 0.104752 | 90.789 | 89.155 |
| 沿用扩散样本原排序 | 0.103678 | 90.790 | 89.146 |
| 移除能量训练读出层 | 0.115012 | 90.730 | 89.146 |
| 仅将已拟合读出层用于 v3 原始头 | 0.097209 | 90.483 | 89.137 |

移除能量训练后，GED@50 从 0.104515 升至 0.115012，差于 v3 的 0.107941。保持相同目标票数、沿用扩散样本原排序，可进一步降至 0.103678，两个 Dice 与完整模型相同。对全部 4,827 个 K 前缀的逐像素检查证实排序仅改变样本成员身份。仅把读出层用于 v3 原始头得到本次最低 GED（0.097209），同时 Dice_soft 降至 90.483%，偏好 Dice 与 v3 相同。以上证据支持能量训练作为 GED 改善的主要来源，并显示新排序在此配置中未带来收益。
