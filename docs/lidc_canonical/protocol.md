## Geometry

Infer middle foreground supports in native CT coordinates using the matching frozen v3 networks. Estimate the soft foreground centroid and a 2x2 covariance. Build a positive-definite affine map which recenters the predicted nodule at (64.5,64.5), normalizes its equivalent moment diameter to 22 or 30 pixels and halves log aspect-ratio differences. Clip each native-pixels-per-canonical-pixel singular value to [0.45,1.80]. Fall back to the native identity on an empty/very small estimate. Resample the CT bicubically; run the original full/zoom v3 networks on both normalized views; return continuous logits by the analytic inverse transform and interpolate smoothly to native logits at unsupported view edges. These operations use image-derived guides only and never impose a label-derived test location. Average the two pulled-back logit fields.
