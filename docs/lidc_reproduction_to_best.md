## 3. 各阶段有效优化：具体改动与证据边界

### 3.1 v1：直接学习四种偏好边界，校正扩散输出

**动机：** 原扩散预测已有多样性，但单个面积秩的轮廓定位仍有误差。

**改动：** 增加残差U-Net，从同一CT及图块坐标预测四面积秩的分割；用四份标注的Dice、加权BCE和有符号距离辅助监督。偏好端融合对应轮廓的距离场；共识端按预测面积分组校正轮廓，并保留原扩散样本相对组均值的形变。每折额外训练4000步，采用八视角推理。

**结果：** 正式Dice_mean由88.0225%升至88.6582%，增加0.6357pp；GED@50由0.116899降至0.113739，Dice_soft@50由89.5100%升至90.1355%。

**能支持的结论：** 加入直接四标注几何监督的组合有效。单独边界模型的Dice_mean更高（88.9765%），但GED变差至0.138429；当时选择融合是为了兼顾分布与偏好，而不是追逐一个指标的外层最大值。坐标先验、额外参数和监督项没有被逐一独立消融。[S1]
详见[边界校正记录](/home/hrl/mohismlab/phd_course/cisc8006/DiffOSeg/docs/lidc_boundary/results.md)。

### 3.2 v3：加入累计票数监督，联合全图与放大视野

**动机：** 相近面积的标注仍可能覆盖不同位置，仅学习“大/小轮廓”不足以表达读者分歧。

**改动：** 同时预测四面积秩掩膜和“至少1/2/3/4票”的四层累计区域；从v1初始化全图、居中放大分支，各训练4000步。用预测票数校准像素在扩散样本中的前景频率，K=10/30/50各自只使用自己的样本前缀。

**结果：** 正式Dice_mean从88.6582%升至89.1374%，增加0.4792pp；GED和Dice_soft同步改善。

**能支持的结论：** 票数监督、双视野及频率校准的整体组合有效；不能将0.4792pp全部归因于某一项。仅图像分支Dice_mean为89.1921%，但完整组合的GED更好，体现了当时的多指标取舍。[S2]
详见[票数监督结果](/home/hrl/mohismlab/phd_course/cisc8006/DiffOSeg/docs/lidc_vote/results.md)。

### 3.3 v4：四秩联合解码与面向最终分布的能量校准

**动机：** 四份偏好概率与累计票数预测可能不一致，单靠边际概率也不能保证合理的空间采样分布。

**改动：** 对同像素四个二值判断枚举16种状态，将偏好概率与票数概率放入同一联合模型；增加共同位置校正。再用能量距离和Dice_soft训练少量频率读出参数，使最终离散采样分布与监督一致。

**结果：** 偏好Dice_mean仅从89.1374%升至89.1463%（+0.0089pp），主要收益是GED@50从0.107941降至0.104515。

**归因边界：** 移除能量读出后GED升至0.115012，支持其分布校准作用；沿用旧扩散排序的GED反而更低，不能把新排序说成有效提升来源。偏好Dice增量的患者区间跨零。[S3]

### 3.5 单切片90%阶段：先解决位置和配准，再做原生网格精修

这是主线最大的一次相邻跃升：**89.1872% → 90.3481%，+1.1608pp**。

**具体改动：**

1. **训练期CT配准。** 只在本折训练患者上，以中间投票轮廓内外的强度差估计二维位移，再做数据增强；原标注和评分坐标不变。四个完整拟合都得到向左、向上各1像素。这是当前PKL数据版本的经验校准，不是可直接推广到其他数据的普遍规律。
2. **单片图像定位。** 先从当前CT估计结节位置；接近中心时保留固定中心，明显偏心时移动视野。定位不读取真实中心，也不读取邻片。
3. **配准图像分支与几何监督。** 从对应折v1初始化，学习四秩分割，增加面积与质心监督。
4. **原生网格精修。** 放大视野的输出回到原128×128网格；另用训练患者的轮廓扰动和CT强度剖面估计等效半径，按图像置信度少量增删边界像素。融合与收缩强度由本折内层库锁定。

**最有解释力的对照：**

| 配准基础分支 | 90.3746 |
| 加入放大视野 | 90.3426 |

固定中心对照与主方案相差0.4140pp；折1由88.1110%升至90.5557%，但定位在折0、2也有退步。配准还有同初始化、同预算的内层对照：

### 3.7 正式E：确定性连续引导与三种子Hiera组合

**改动：**

- 在同片预测链上引入SAM2.1 Hiera-Tiny三级图像特征及三个独立种子的解码器，每个成员固定5000步、EMA，使用本折真实患者折外引导。
- 三成员先各自保存为fp16，再以fp32等权平均连续logits；四折新增分支权重均在外层推理前锁定为0.25。

**为何另设正式E：** 原正式B已完成12个新模型，但折2无法重现旧连续引导哈希，没有完整外层分数。E是另行登记、重新生成四折引导及预测的算法；它不是从B的某次重放中事后挑选较好的结果。

## 4. 最终选定方法与分折表现

### 最终推理关系

对当前CT生成确定性连续引导g，其符号与同图像的冻结A二值预测一致；三个Hiera成员输出z1、z2、z3。最终按下式二值化：

```text
z_bar = float32_mean(fp16(z1), fp16(z2), fp16(z3))
prediction = (0.75 * g + 0.25 * z_bar) > 0
```

这里g包含前述图像分支、确定性轮廓精修和A模型的信息，不是简单把A二值掩膜变成常数logit。最终系统有多级冻结模型和同图像预测缓存依赖，不能当作仅凭一个新checkpoint就可独立重放的模型。也不能把所有历史支线都画进最终偏好推理链；例如v8共识投影的收益没有被重新测试为E的GED收益。
