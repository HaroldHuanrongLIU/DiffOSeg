## Model

Using only the original 128x128 LIDC image and fixed patch coordinates, train a periodic angular network on 96 rays about the protocol's fixed crop origin (64.5,64.5). Fit four area-ranked radii per angle from radially integrated expert occupancy. A further head estimates the local disagreement between experts. This is a working shape prior; holes, satellites, multiple crossings and eccentric objects are represented more faithfully by the existing Cartesian branch. Fit the polar net from scratch for a fixed 4000 updates, AdamW, batch 48, EMA, with seed 42901 + fold and radial, rotation/reflection, small origin and intensity augmentation. Use the final weights. Verify finite outputs, GPU backprop and an inner polar-only aligned Dice of at least 0.78 before proceeding to full-fold fit. All development and calibration use only that fold's original outer training patients.

## Calibration and inference

Reuse v1's inner split and its genuinely inner-trained Cartesian checkpoint. Split its inner validation patients deterministically in half by patient (seed 4680 + fold); the first half supplies an empirical residual library, the second selects two parameters. Model per-rater radius error relative to the case's four-rater mean after removing the predicted rank effect. Estimate standardized angular error profiles from annotations on library patients, with zero cross-rater common shift. Rotate/reflect a sampled profile and scale by the predicted local disagreement and a calibrated multiplier at inference. Keep the sampled angular shape intact. Reuse the library and parameters locked on inner data with the full training models, preserving patient independence.

Pick the polar fraction from {0.25,0.50,0.75} by highest aligned Dice in the selection half. Blend polar and Cartesian boundary fields before thresholding. Then select residual scale from {0.65,1.00,1.35,1.75,2.25}, minimizing mean GED@50 of the image-conditioned sample bank there (tie: first listed). All candidate values, patient counts and observed metrics are saved. Inner calibration targets the new image-conditioned module alone: external frozen diffusion outputs belong to models trained on inner validation, so cannot participate in this selection. The full predictor adds a fixed 15% of the corresponding v1 preference distance field, or uses a fixed 15% v1 consensus draw distance plus 85% of the learned noisy rank field. Match ranks by each prefix's predicted area and use only that prefix. Use fixed case-specific random draws independent of labels. This adds one polar network per fold and reuses the v1 checkpoints and masked predictions. Evaluate the deterministic image-conditioned contour ablation (zero perturbation, without v1 output blending) alongside the full model.
