## 方法与研究轨迹

v3 学习两组不同的监督信号。第一组是按面积排列的四份专家标注，第二组是每个像素至少获得 1、2、3、4 票的四层掩膜。第二组可以区分几何位置分歧与轮廓大小差异，即使两位专家的轮廓面积相近、覆盖部位不同也可表达。模型从对应 v1 折内权重初始化，分别训练全图分支和居中 80 像素的放大分支。利用预测票数估计前景出现频率后，对每个像素按 v1 扩散轮廓的有符号距离排序，选择目标数量的样本保留该像素。K=10、30、50 分别仅使用原先同一前缀，预测阶段只输入 CT 和已有预测。

每折各分支额外训练 4,000 步，批量 24；两个新网络合计 4,396,152 个参数，均使用八种几何视角推理。每种视野先单独训练内层模型，再用所有外层训练患者重训。v1 模型和归档扩散样本也属于部署依赖。完整模型相比仅图像分支降低 GED@50（0.130361 → 0.107941），提高 Dice_soft@50（90.512% → 90.696%），但偏好平均 Dice 略低（89.192% → 89.137%）。这一对照评估了组合方法，未单独分解双视野、额外参数与损失的各自贡献。

在 v3 前，v2 测试了极坐标轮廓和从内层标注学习的角向形状扰动，同时改善三项指标的假设未获支持。其 GED@50 为 0.116139，Dice_soft@50 为 89.198%，偏好平均 Dice 为 88.621%。v2 全部结果保留。v3 的内层选参使用 v2 的图像分支产生替代样本库，外层使用 v1 的真实扩散输出。E11 原始检查点训练时已见内层验证患者，直接用于内层选参会引入泄漏。[v2 负结果](../lidc_polar/results.md) · [v3 实验前登记方案](protocol.md)
