# 轮廓外延的方向性 CT 强度检验

起点使用已完成患者来源审计的两级折外教师 U、S，在原内层折 0、1 的拟合患者上检验沿轮廓外法线延续的亮组织能否预测局部错误。每个图块仅用其注册的当张 CT 和两教师平均 logits Q。对每个面积秩仅在 Q 二值轮廓内外 2.5 像素带中尝试修正，分别从有符号距离梯度获得外法线。图像按本图块预测内部与邻域归一化。两组具有完全相同的基线概率、两教师分歧、面积秩、模型大小、距离、局部灰度和梯度等特征。额外读取沿指定方向的 2、4、7 像素处中心强度、与两侧 2 像素的强度差，以及相反方向的中心强度。主方法使用外法线；控制旋转 90 度，使用等数量的切向采样与同样的运算。

训练每个像素的目标为实际二值标签减 Q 的 sigmoid 概率。采用 70 轮、最多 9 个叶、最小叶样本 80、学习率 0.07、L2 为 10 的直方图梯度提升回归。每图块患者均衡与图块等权各半，秩内再按预测面积倒数加权。将预测的概率残差乘固定 0.75 后加回原概率，按 0.5 取掩膜。三个原教师留出组分别再按患者三分，在同一教师留出组的另外两份训练回归器并预测剩余一份。每病例仅用彼此均排除该患者的上游教师和下游回归器。先封存两折全部预测，再独立按原始标注评分。只有主方法相对起始提示在两个拟合折都提高、均值至少 +0.08 个百分点，且平均比切向控制高至少 +0.02 个百分点，才另行扩展到真实内层 E 检查。本实验检验方向性强度，不给像素赋予血管等未经标注的临床身份。正式目标为原 214 患者单片四折 Dice_mean ≥0.910000。
