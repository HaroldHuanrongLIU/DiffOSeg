# 单片层级图像特征的匹配试验

原单切片四折偏好平均 Dice 为 90.4531%。先前增加 SAM ViT-H 容量及把原 ViT-B 输入提高到 1024 均未改善四折内层结果。当前改动检验不同空间步幅的预训练图像特征是否提供额外边界线索。只用现有 LIDC 标注训练，不引入其他医学数据。使用通用图像/视频预训练 SAM 2.1 Hiera-Tiny 的图像模块，每个病例只读当前 CT，不构造视频序列，不使用跟踪、记忆、患者身份或邻片。

两组使用相同公开通用权重、折内患者、四种整转、按原方案注册的 512 像素单片、OOF 自动引导、解码器及 5000 步预算。固定图像主干。临床监督来自原四份面积排序掩膜。提取图像编码金字塔特征，使用公开的对应投影把 128、64、32 空间分辨率的连续特征保存为独立图像缓存。最深层沿用官方无记忆图像嵌入。对照在掩膜解码器的两个高分辨率加法位置使用零值；主要候选放入真实的同片高分辨率特征。两组都训练公开提示编码器与掩膜解码器，加上完全相同的原生 CT 细节和引导残差。四个原生 mask token 分别学习四份面积偏好，保留 Dice、加权 BCE、原始解码损失及半径损失。

在折 0、1 内层首先验证。拟合病例的引导来自排除此患者的教师。部署时以正式模型的单片预测为引导，固定原始四视角推理；在每折库患者上选 0、0.25、0.5、0.75、1 的融合权重，在独立检查患者复算。主要候选须在两折均超过同机低分辨率对照且两折平均较正式内层参照至少高 0.03 个百分点，方可扩展其余折。必须报告单独模型和最终融合结果。该门槛只用于内层晋级，原外层验收目标仍为 0.910000。预训练的来源、规模及推理计算应与最初 DiffOSeg 分别披露。
