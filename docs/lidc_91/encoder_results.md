# LIDC 编码器适配的四折内层结果

将原始 SAM 的最后四个图像编码模块和卷积输出层与提示解码器一起微调，四折内层偏好 Dice 为 **90.5321%**。共同对照为 90.4192%，等训练量的冻结编码器对照为 90.4746%。两组均从各折已训练 5,000 步的提示解码器开始，再训练 5,000 步。医学监督仅来自现有 LIDC 训练标注。

| 折 | 共同对照 (%) | 继续训练解码器 (%) | 同时适配编码器 (%) |
|---|---:|---:|---:|
| 0 | 90.1708 | 90.1708 | 90.2313 |
| 1 | 90.4666 | 90.5548 | 90.6657 |
| 2 | 90.5780 | 90.7275 | 90.7679 |
| 3 | 90.4616 | 90.4454 | 90.4636 |
| 四折等权 | **90.4192** | **90.4746** | **90.5321** |

适配组相对共同对照增加 0.1129 个百分点，条件配对 95% 区间为 +0.0323 至 +0.1796 个百分点。相对等训练量冻结对照增加 0.0575 个百分点，区间为 −0.0063 至 +0.1245 个百分点。四折点估计均提高，但后一项区间跨零。区间来自 5,000 次患者 bootstrap，同一患者在不同折中使用一致权重。这里共有 507 次图块检查、60 位不同患者，且同一内层队列已经反复用于方法开发。

编码器前八个模块的分解在两个实际图块上与完整前向逐值相同，特征缓存量化的相对 RMSE 为 0.00524。所有实际选定的掩膜均经独立集合交集复算。等训练量两组采用相同初始模型、病例采样、增强序列和训练步数。该实验只评估内层患者，外层状态为 **NOT_RUN**，原外层主结果继续为 90.3481%。

为判断标量融合的空间，还使用内层真值计算了一组仅供诊断的选择上限。基于两套已存 logits，即使由真值选择每折统一权重，四折均值也只有 90.5940%。允许每例独立选择权重为 91.0033%，允许每例每个面积等级独立选择为 91.2684%，允许逐像素选择为 91.9430%。这些结果依赖评分标签，不可用于部署或 91% 验收。
