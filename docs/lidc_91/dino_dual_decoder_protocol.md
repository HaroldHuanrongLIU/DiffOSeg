# 用双尺度自监督特征预测完整面积秩掩膜

局部表征的拟合盲测只在已有轮廓的 2.5 像素带内训练像素回归器。这里另行检验全掩膜训练。将固定 DINOv2-Large 的 128 像素与 64 像素视图映射到相同原生坐标，再将视觉特征加入两级 U-Net 解码特征。主方法用全图和局部 token，等容量控制将全图 token 同时送入两个通道组。两者从同一 v1 权重开始配准阶段的完整 6000 步训练，使用相同患者、种子、几何与强度增强、损失、末步 EMA。两种零初始化适配器在开始时都须精确重现原主体输出。新增的是通用自监督图像信息，医学标注只用现有四份 LIDC 掩膜。

先比较原内层折 0、1。拟合 token 使用已验证的两级患者排除教师中心，复用逐图冻结的 DINO 图块。验证两种尺度的缓存身份和病例顺序。库与检查中心从本图块 E 的单片连续引导生成，无人工提示，采用同一冻结权重、随机投影和原生坐标映射，逐图编码。局部视野以外回退全图 token。把 128 通道特征采样到当前图像视角的 64 与 128 空间尺度，分别通过 128→24→40 和 128→24→24 的 1×1 适配器加入 U-Net 倒数第二层与末层解码输出。适配器创建不改变原采样随机序列，末层投影零初始化。原配准 24 视角推理回到 128×128，直接预测全部四份掩膜。记录两个模型独立的逐秩和完整模型 Dice。每组在本折库患者从 0、0.25、0.5、0.75、1 中选择新模型 logits 与 E 连续 logits 的混合比例，再封存检查预测。所有检查预测封存后使用原标签评分。

只有双尺度方法在两个折均超过 E、平均至少 +0.05 个百分点，并相对全图同容量控制平均至少 +0.02 个百分点，才登记其他两折复验。拟合诊断、单独模型分数与内层均不充当原外层验收。最终指标是 214 位患者当前 CT 单片上原四折未舍入 Dice_mean 至少 0.910000。
