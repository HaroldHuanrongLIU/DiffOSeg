# 从冻结的二值偏好预测构造可重算的连续提示

正式 B 的折 0、1、3 均重现历史连续引导哈希，并逐像素重现 A 掩膜。折 2 的默认及独占显存重放未重现历史哈希。两次只比较旧模型的诊断重放分别与已封存 A 掩膜相差 19、31 个像素。原 B 严格流程保留为未完成，新增外层标签及分数尚未开放。此次方案是单独登记的新算法，不把较弱校验替代原门槛。

现在可验证地取得每一折原 A 的完整二值输出。以这些输出和当前 CT 确定一个连续提示。对每个面积秩和前景/背景分别用确定性的 CPU 欧氏距离计算其距边界的像素距离，取绝对距离减去半像素、截断于 8 后的整数区间。将已根据该折训练估计配准的 CT 灰度按当前切片四秩中间支持的内部与外 1 至 8 像素环的中位灰度归一化，最小宽 12 灰度级，以 0、0.25、0.5、0.75、1 作五个分界。仅用该折内层库患者原 A 已存档的连续输出学习提示幅值表：先对每图块每个区间的 log(1+幅值) 取均值，再在患者内、患者间等权平均。CT 灰度细分表以五个患者的伪计数收缩到距离表。稀少距离区间取本等级同符号最近的观察区间，完全没有观察时用距离。逆变换后将幅值限制在 0.05 至 12。最终符号严格由存档二值掩膜确定。主要方法用距离和灰度，控制仅用距离。两法均不需要重新生成历史连续场，正式推理只读当前切片、其冻结医学模型的二值预测以及本折已锁定的表。

三个 SAM2 模型的训练输入、医学标签、公共图像特征、种子和 5000 步 OOF 拟合与前一三种子试验完全一致，因此复用已拟合权重。重新为库和检查数据构造新的提示、运行三个模型、选择权重并独立评分。半精度成员 logits 等权平均后再与新的连续提示融合。各折主方法与控制的库内融合权重及预测统一封存，再计算同一四折的检查分数。本次开发折已在先前试验中使用，不作为新的独立队列。只有主要方法相对正式 A 的四折内层增量至少 +0.05 个百分点、至少三折提高，并且四折均值不比已登记的连续引导组合 90.620235% 低超过 0.05 个百分点时，才进行新的原四折正式实验。

若晋级，另行锁定正式 C，使用相同训练配方经核验的全部外层训练患者权重。对包括折 0、1 在内的四折一律以新的确定性提示重新推理，全部封存后再评分，不能拼接原 B 的任何预测。仍以原 214 位患者、1609 个单片、四份标注面积稳定排序、四折等权 Dice_mean ≥ 0.910000 验收。
