# 在四秩一致区域预测部分面积秩的错误

原折 0、1 的拟合患者中，两个排除教师平均预测的四秩全为背景而真值全为前景，分别有 375、774 个像素；相反情形为 3027、592 个像素。若只能纠正这些四秩共同错误，读取真值可提高 0.3201、0.1584 个百分点。放宽为预测四秩一致区域最靠近其边界的 2.5 像素，并允许各秩分别纠正，读取所有真值能提高 4.1357、3.9134 个百分点。该区域中约 20.3%、19.6% 的像素至少有一秩错误。上述数值是拟合范围的误差诊断。

以此处的单片 CT、当前两教师的四个 logits、预测几何与局部 CT 统计作为输入。只考虑四秩均为背景或均为前景、且到该一致区域外部的原生距离减半不超过 2.5 像素（像素中心间距离减 0.5）。主方法用二分类事件头预测任一秩错误的概率，再仅在拟合真值事件阳性的像素上学习目标面积秩错误的条件概率。部署时相乘得到各秩错误概率。直接控制在所有相同像素上直接预测各秩错误概率；另报告选择主方法条件头但给出真实事件的纯诊断。输出逐秩判定，在原背景像素概率超过 0.50 时添加、原前景像素概率超过 0.60 时去除；其他像素完全保留。这对应名义 Dice 0.90 的单像素收益判定再加 0.05 的保守幅度。三个分类器均为 60 轮、最多 9 叶、叶至少 100、L2 为 10、学习率 0.07。训练像素只使用固定棋盘格的一半，推理对全部区域执行；训练权重按图块/患者各半并按预测面积的倒数校正。主方法的额外事件头需单列。

只在原折 0、1 拟合范围作初步验证。三个原教师留出组内分别再按患者三分，事件头、条件头和上游教师全部排除接受评分的患者。两折先封存再独立从原始标注复算，包括每项修改的原预测一致性、空间带、事件概率和诊断值。主要方法相对起始提示两折均提高、平均至少 +0.08 个百分点、并比直接控制高至少 +0.02 个百分点才继续到原内层 E。最终验收仍为原四折单片 Dice_mean 至少 0.910000。
