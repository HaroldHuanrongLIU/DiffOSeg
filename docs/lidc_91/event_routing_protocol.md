# 在高风险一致区域用互斥患者预测提出修正

上轮封存的事件概率在四秩一致的窄带上估计“至少一秩错误”，多数样本未达到固定的概率翻转门槛。这次分别检验排序和实际使用效果。仅使用原折 0、1 的拟合患者。每个病例在此前严格患者排除的事件概率对应位置上，固定取最高 20%（向上取整，概率并列按原栅格索引）；记录真实事件比例及捕获的事件比例。位置控制取相同数量、最接近一致区域边界的像素，并列按同样顺序。另报告按原有四秩连续 logits 中最弱的绝对幅度选取相同数量的位置。

每一位置每一秩的纠正来源为两个由互斥拟合患者训练、且都排除了目标患者的辅助模型。只在两者都给出与当前一致符号相反的符号时翻转该秩。主方法仅在事件概率最高的预算内使用这项修正，对照分别为边界距离排序、最弱原生置信度排序和不限制预算的双模型一致修正。所有方法的坐标与类别均来自同一单片现有预测，无真实事件、面积或读者身份输入。诊断另报告在相同选点上允许读取真值时的最高 Dice；它仅区分位置和符号判断的能力。两折分别封存全部掩膜，再从原始四份标注独立核验。只有主方法相对起始提示两折均正、平均至少 +0.08 个百分点，并相对三个对照各平均至少 +0.02 个百分点，才登记内层 E 比较。相同拟合患者已经用于生成假设，本次仍属于开发诊断。正式目标仍为原患者单片四折未舍入 Dice_mean ≥0.910000。
