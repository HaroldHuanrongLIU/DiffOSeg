This fold-1 pilot instead tests whether increasing the nodule's scale within a 512-pixel public SAM view improves the native 128-pixel prediction. Earlier U-Net magnification gave mixed results; the SAM experiment tests the feature resolution of a different encoder. Prespecify a paired whole-patch control and an image-guided local candidate.
