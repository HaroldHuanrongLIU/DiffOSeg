# Training with uncertainty in close annotation-area ranks

The accepted outer preference Dice is 0.9045313485402589. In fitting patients only, adjacent equivalent-radius gaps at most 0.5 native pixels accounted for 55.05% of pairs in fold 0 and 53.38% in fold 1. Among these near pairs, 12.45% and 11.89% respectively had intermask Dice below 0.85. Close areas can correspond to different shapes. This motivates a training regularizer for the four area-sorted simulated preferences.

For each fitting case, add the four fixed offsets -0.75, -0.25, 0.25, 0.75 native pixels to its four equivalent radii in all 24 permutations. Sort each perturbed vector and average the resulting permutation matrices. Mix this doubly stochastic matrix equally with identity. Compute the expected per-rank foreground Dice and weighted binary cross-entropy over those assignments for the main and raw decoder predictions. Preserve the original rank-specific area objective. This is a finite label regularizer, and the offsets are a design choice rather than an estimated radiologist noise distribution. The four original masks are the only clinical targets. No rank perturbation or reference label enters inference or scoring.

Use the same original SA-1B ViT-B, live frozen prefix, adapted last four image blocks and neck, 5000-step warm prompt decoder, patient-out-of-fit guides, seeds, 5000 additional updates, batch 12, EMA and native evaluation as the paired live-frozen controls. Check deterministic assignment, conservation of all four ranks, equality to ordinary loss for well-separated radii, and agreement with direct weighted pair losses for fractional targets. Compare the ordinary component of the first loss against the existing control to verify the sampled batch and initialization. Run fold 0 on Lakers and fold 1 on E11. Lock the same library fusion weights before checking each fold. These are two prespecified inner pilots; the original four-fold threshold remains 0.910000.
