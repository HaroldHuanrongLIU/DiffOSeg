# 当前 CT 引导的 DINO 特征上采样结果

固定64×64特征网格的 AnyUp 方案完成原内层折0、1。两折平均 Dice 为 **90.563043%**，相对同折 E 增加 **0.045344 个百分点**，但未超过同可训练容量的双线性控制，未通过预先设定的晋级条件。正式 E 为 0.9052097376196222，本轮原外层为 NOT_RUN。

本次新增冻结的 AnyUp 论文上采样器，公开权重含 878080 个参数，作者在 ImageNet 图像上用冻结特征匹配训练。它先接收当前单片的原始 DINOv2-S 32×32×384 特征与规范化 CT，再输出64×64特征，随后使用该折拟合患者的原 PCA 降为64维。所有新增医学监督均为已有 LIDC 四标注。源码固定于 commit `351807a9c4287368732cc247f26c7c81c9139af4`，采用 standard attention，未使用 NATTEN。权重 SHA-256 为 `9d035c0f27114a6f32bdd3d8ed93b6cd39dad4b8f8bf94e69fddbfbf022901b2`。[作者实现](https://github.com/wimmerth/anyup) · [原论文](https://arxiv.org/abs/2510.12764)

三组共用原 DINO 粗层分支，增加相同的64→48→64细分支适配器到 Hiera 的64尺度；仅细特征生成方式不同。双线性组直接放大原特征，模糊组由同一CT的固定高斯模糊版本引导AnyUp，主方法使用原CT引导。PCA在AnyUp之后执行。三组解码器均为4240217个可训练参数，相对E增加21920，相对原粗层DINO增加6256。AnyUp两组还额外调用冻结上采样器。每折、每组采用相同三个种子、5000步、原损失和EMA。最终输出为原 .75 引导加 .25 三成员平均。
