# 以配准图像模型恢复 CT 局部置信度

正式 B 在折 2 无法重现历史 v9 法线精修连续场，旧输入两次重放有 2566 项数值不同；配准 U-Net 和放大 U-Net 的输出在这两次重放中逐字节相同。只按已存档二值掩膜的距离和灰度查表，四折主要候选相对正式 A 为 −0.0014 个百分点，未晋级。此次检验是否能从冻结的配准图像模型保留逐像素置信度并避开引起漂移的分支。在提出此假设时原 B 没有新外层评分。

各折统一从当前切片的定位器、注册 CT 的全视野 U-Net 及放大视野 U-Net 生成连续场。定位、配准位移、原内层已锁定的质心收缩强度、放大比例和空间窗采用已训练的单片方法。全视野置信度在全部折均仅使用配准 U-Net 的连续输出，不再混入 v9 的连续值。按已存档 v10 二值输出确定其正负号。用同一折先前已训练的 A 的图像 SAM 适配权重处理此新引导，再用原 A 各折已冻结的 A 分支比例组合，所得幅值与已存档的 A 二值符号构成主方法的提示。对照直接使用全视野与放大 U-Net 的幅值，以相同 A 二值符号输出。两种方式只依赖当前 CT、冻结图像模型和其二值预测。对前景和背景对称使用最小幅值 0.05。三个 SAM2 模型、训练范围、种子和融合规则与已登记异构组合相同，原完整训练患者的已核验权重可复用。

输入和提示在两次独立进程中按相同设置生成，要求原生注册连续场和最终提示均逐字节一致，保存数组、哈希和来源图像索引。该算法不要求等于旧且未存档的 v9 连续输入。禁用 cuDNN 自动调优，开启 PyTorch 确定性算法并显式配置 CUDA 矩阵乘工作区。四折内层库各自锁定原五个融合权重，再统一评分独立检查患者。主要候选只有在四折平均相对正式 A 至少 +0.05 个百分点、至少三折为正、折 2 相对参照持平或提高且两次提示重放一致时，才可进行另行锁定的原四折正式复评。控制与主要候选均保留。此次开发涉及已经检查过的患者，须报告患者配对区间。

若通过，在全四折均重新生成本算法的引导和预测，独立核验，不代用正式 B 任何已封存的新增预测。每折全部 3 个完整训练患者模型只使用该折 LIDC；正式推理只用单切片。目标仍是原 214 位患者、1609 个图块、面积稳定排序四偏好 Dice 的四折等权未舍入均值 ≥0.910000。
