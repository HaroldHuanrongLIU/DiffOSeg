# 直接预测秩间伸缩的 Dice 收益

原折 0、1 的拟合诊断发现，同一动作族中，按真实间隔与按真实 Dice 选择的结果存在差距。本假设直接拟合动作的 Dice 收益，在原折 2、3 的拟合范围使用已核验的单级患者排除预测作为起点。这些原折的拟合患者可能与前述研究重叠，但本方案的样本顺序、教师和选择规则均在读新分数前固定。

保持已定义的八个动作、±2 像素步长上限、三像素带和四秩等权。对每一训练病例，计算各动作相对零动作的真实 Dice 增量（百分点），用无截距二次曲线 b·t−c·t² 拟合这八个收益，t 为动作尺度的对数。将 b、c 截断于 ±8 后用加权岭回归预测，拟合权重图块和患者各占一半，L2 为 30。主方法使用秩半径、周长、六对预测对称差、每个动作的离散度变化和四秩轮廓内外的 CT 强度/梯度均值。两个控制分别去掉 CT 输入和只用训练患者加权平均系数。推理时令 c≥0，选择预测收益最高的动作；最高收益低于 +0.05 个百分点时保留原掩膜。额外报告真实逐例最优动作及用真实拟合系数选动作的诊断成绩。

每个原教师留出组内再按患者三分，拟合动作回归和上游教师都排除被评估患者。两折均锁定后才读取正式诊断分数。要求主方法相对起始提示两折均正且平均至少 +0.08 个百分点，平均比两个控制各高至少 +0.02 个百分点，才扩展至内层 E。所有阈值均沿用四秩等权 Dice。正式目标仍为原单切片四折点估计 ≥0.910000。
