# Conditional Dice for candidate foreground areas

The accepted outer result is 0.9045313485402589. Earlier training-only diagnostics found considerable headroom with the true area, while point-radius regression and a native fixed-area network gave limited improvements. Test whether predicting the actual Dice change of a proposed area is more effective than predicting the radius. This study is independent of the running ViT-H capacity comparison.

For one rank, order native pixels by the frozen image score. The mask with its first k pixels has Dice equal to twice the prefix intersection with the annotation divided by k plus the annotation area, with the original empty convention. One observed mask gives a realized utility for every area in this family. The predictor estimates conditional mean utility differences from single-image features. The numerical search restricts decisions to these ordered prefixes. The decision is related to the expected F-measure objective of [Dembczynski et al., NeurIPS 2011](https://proceedings.neurips.cc/paper/2011/hash/71ad16ad2c4d81f348082ff6c4b20768-Abstract.html).

Use the existing patient-out-of-fit contour guides on inner fitting patients. Evaluate equivalent-radius offsets from -4 to +4 pixels in 0.25-pixel increments, including the exact original mask. Features include the rank, predicted areas and disagreement, single-slice CT intensity, contrast and gradients in the candidate region and adjacent score bands, and 12 PCA components of frozen public SAM foreground-versus-background features. Fit the PCA and the regressors exclusively on inner fitting patients. Use histogram gradient boosting with 150 iterations, learning rate 0.06, 15 leaves, at least 80 samples per leaf, L2 regularization 8, and seed 94171+fold. Give patients and slices equal total weight in a 50/50 mixture.

Use the accepted fold-specific ViT-B or CT-adapted fusion as the guide on library and check patients. The primary method chooses the offset with the largest estimated Dice improvement. A matched control predicts the point radius residual with the same feature family and regressor settings. For each approach, select a common shrinkage strength from 0, 0.25, 0.5, 0.75, 1 on library patients before checking. Include a rank-specific fixed-offset control fitted on library patients. Do not choose primary and control labels retrospectively. At inference the method uses the current image, frozen image features and predicted guide only. Report all four original inner checks, reproduce selected masks independently, and keep the outer 91% goal intact.
