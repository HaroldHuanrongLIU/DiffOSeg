# 按四秩预测面积配对的病例混合训练

仅用原折 0、1 的拟合患者。按当前批内、不同患者、四秩 OOF 引导的对数面积做匹配。两折各抽 256 批作训练诊断，相对循环选取不同患者，真实标注间 Dice 从 63.8355%、65.6305% 提高到 73.9732%、75.4806%，跨患者比例均为 100%。这些值只测供体匹配质量。

同一公开 Hiera-Tiny 和 E 解码器在 Lakers 分别训练了两折、每折两个模型，每个 5000 步。偶数步按 0.75/0.25 混合两个病例的 CT、引导和缓存特征，再按相同比例加权两份原始四秩分割损失；奇数步普通监督。初始损失与原 E 核对，训练批次和旋转在抽查的两个步骤匹配。五步真实烟测通过。推理仍是原单片，替换三成员中的第一个，重放原三成员时逐像素重现 E。两折预测全数封存后评分。
