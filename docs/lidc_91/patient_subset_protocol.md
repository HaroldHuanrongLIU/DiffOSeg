# 互斥患者组的主体集成是否改善单片预测

现有三个患者组和患者排除教师，允许在拟合范围直接观察训练患者多样性。对组 C 中的病例，原排除教师 U_AB 训练于 A、B；另有两个相同架构单例教师 U_A、U_B，分别只训练于 A 或 B。三者都没有拟合 C。用真实单片 CT 产生预测，使用相同的 4500 步预算、确定性配准和既有推理流程；两个小组模型合起来覆盖大组模型使用的同一批患者。此前使用这三个组训练第二层解码器的方案不同，本研究直接测量保留各小组模型预测的效果。

只用原内层折 0、1 的拟合图块，核对三个子银行里的原病例顺序、供体身份、拟合和排除集合及全套权重。主要方法按两训练规模各占一半作平均，Q = 0.5 U_AB + 0.25 U_A + 0.25 U_B。比较 U_AB、两个单例均值，以及额外的确定性诊断 2 U_AB − 0.5(U_A+U_B)（向相反方向延长规模差）。所有系数在读取这项比较的结果前固定。三种模型均以半精度保存的原生 logits 为输入，使用 float32 算术再取正号。记录两个单例自身成绩、每折四秩原始 Dice 和患者配对区间。只有主要方法在两折均优于 U_AB、均值至少 +0.08 个百分点，且均值相对仅单例平均至少 +0.02 个百分点，才登记把患者组集成应用到内层 E 的独立检查。这里的质量只属于拟合患者诊断，正式目标仍是 214 患者的单片四折 Dice_mean ≥0.910000。
