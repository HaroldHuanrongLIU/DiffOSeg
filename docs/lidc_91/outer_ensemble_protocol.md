# 原患者四折的三种子异构组合正式复评

原单切片四折的当前正式偏好 Dice_mean 是 0.9045313485402589，指定 E11 基线为 0.8802246254490422。内层三种子组合已达到预订门槛，全四折平均提高 0.079086 个百分点，作为复验的折 2、3 平均提高 0.090271 个百分点。四折各自均为正。冻结内层报告 SHA-256 为 `1eb13a03183e78b509bc51d537564300ed5b601f1c60201d06f0f954e771422b`。内层患者配对区间跨零；正式复评以冻结预测的外层证据判定。

所有折使用同一已登记算法。每折在所有原外层训练患者上重新拟合三个 SAM2.1 Hiera-Tiny 金字塔解码器，种子 50171+fold、67171+fold、84171+fold，批量 12，5000 步，最终 EMA。复用经校验的原训练患者三路交叉拟合教师引导；每一例的训练提示均来自未拟合该患者的教师。公共单片图像特征与内层实验完全相同，冻结其数据、权重、源码和特征哈希。所有医学监督只取本折 LIDC 训练患者。每折对三个输出先半精度保存，再用 float32 等权平均。只从本折内层库锁定的原五个融合权重带入正式训练，四折的新分支权重均为 0.25。

正式 A 只归档了最终二值掩膜。用原 A 的 `checked-source` 冻结实现、同一权重和缓存重建单片连续引导，逐折将原输入对照 A 的存档哈希，并重放 A 的二值输出与其原封存掩膜比较。用原存档二值掩膜确定连续引导的正负号，分数幅值按内层程序由原 v10 引导与半精度 A 分支 logits 加权后取绝对值，最低幅度 0.05。不得将真实标签用于推理。报告重放的一致性；若旧引导哈希或重放二值身份不符，先调查并保留失败记录。联合平均、三个种子和权重均在产生新外层预测前锁定。

四折全部预测封存后统一计分。使用 E11 的 214 位患者、1609 个图块、四份面积稳定排序的二值掩膜；折内各图块及四偏好等权，四折等权。重算 E11、正式 A 与新组合的逐例四秩分数，报告分折及四秩均值、按折分层的 5000 次患者配对 bootstrap。另用独立实现从原始参考掩膜和预测像素集合复算全部 19308 项 Dice，核对原患者互斥、索引覆盖和各对照的冻结结果。新组合可能优于或劣于正式 A，均保留并报告。只有未经四舍五入的四折 Dice_mean ≥ 0.910000 才满足 91% 目标。该队列已多次用于模型开发和复评，正式结果仍属同队列证据。
