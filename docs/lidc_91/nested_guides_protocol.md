# 两级患者交叉拟合的训练提示

目前正式 E 为 90.520974%。原 U-Net 排除教师对内层拟合患者的四秩 Dice 在折 0、1 分别为 90.0314%、90.1918%。推理中使用较强的现有单片模型，而训练提示来自不同强度的教师。此次检验加强训练提示本身能否提高对 E 的后续单片校正，而不让拟合病例自己的标签进入其提示生成过程。

沿用各原折拟合患者的三个既有互斥组 A、B、C。第一层额外从头训练三个 U-Net，每个只见一个组，使用原 4500 步、患者内 CT 配准估计及原损失。在训练用于预测 C 的第二层 Hiera 解码器时，A 的提示只由 B 教师产生，B 的提示只由 A 教师产生；该解码器的医学训练病例只有 A、B，对另外两种留组方式轮换。验证 AB 单独估计的 CT 配准位移与公共特征缓存一致，三者都排除 C。预测 C 时以已经核验的、只训练 A∪B 的原 U-Net 输出为输入。固定 Tiny 图像特征，每个二级解码器从通用公开权重出发训练 5000 步，批量 12、最终 EMA；不同子组的登记种子为 155171+fold+317×子组号。二级输出与该病例原排除教师连续 logits 各 1/2。将三个留组的预测按照原病例排序合并，覆盖完整拟合患者一次。第一、二层均保留每个检查点的患者来源与教师依赖。不得用在某患者或其其他切片上拟合过的教师，直接或间接生成该患者的训练用二级提示。

先按原折 0、1 做训练范围内的质量检验：混合后的二级教师须在两折都超过原排除教师且平均增加至少 +0.05 个百分点，才启动最终学生。此处只衡量训练提示本身的质量，不作为内层或原外层成绩。若通过，再在原内层拟合范围上以新的 5000 步 Hiera 解码器学习，拟合组、种子 189171+fold、结构和预算完全匹配。控制用原一级 OOF 提示；主方法只将该训练输入替换为确实排除本患者的二级提示。两个学生在检查患者上均以同一张 CT 上复算的 E 连续预测为引导，采用原始单片四视角和原有五个库内融合权重，多层冻结身份与准确 E 二值符号都需核验。两折先封存后统一评分。主方法相对 E 两折平均至少 +0.05 个百分点、任一折不低于 E 超过 0.03 个百分点且相对一级提示控制平均至少 +0.025 个百分点，才可扩展。保留未通过的阶段；只有原 214 患者、1609 张单片正式四折的未舍入 Dice_mean ≥0.910000 才验收。
