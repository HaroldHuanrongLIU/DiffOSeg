# 同片锐度响应能否预测面积误差

以前的面积修正主要使用单次预测、多个教师的分歧和轮廓附近的组织特征。本研究检验同一模型对对称锐度扰动的响应是否提供额外信息。输入仍为现有单切片 128×128 CT。对每个原折 0、1 的拟合病例，沿用确实排除了该患者的一级教师及原始定位中心。在原 8 位像素值上用标准差 1.2 的高斯平滑构造高频残差，分别减去和加上 0.6 倍残差，裁剪到 [0,255] 并舍入。两种扰动与原图使用相同配准、相同中心和 24 个视角；另重放未扰动图，记录与已封存一级预测的二值差异。允许每折相对原前景的二值差异至多 0.1%，否则中止并排查。

起始候选仍是一级与二级患者排除教师的均值提示 Q。已有的图像、形状面积回归作为基础控制。主方法增加各秩在锐化、模糊后相对原图的等效半径差、交并变化及近边界概率差。加入匹配控制：用同一病例同一响应的绝对值，移除锐度变化的方向。另有直接平均三个一级预测再与二级提示融合的无学习对照。拟合真实半径减当前半径，截断至 ±3；采用现有的患者/病例等权、标准化岭回归、L2 30、固定半强度位移与原置信排序取目标面积。组内严格按患者再三分，上游教师和下游回归器全部排除接受评分的患者。所有病例只预测一次，原始标注独立复算。只有主方法相对 Q 在两折均提高且平均至少 +0.08 个百分点，并相对基础控制、无方向控制、直接平均各高至少 +0.02 个百分点，才另行登记真实内层验证。原正式四折 Dice_mean 的 0.910000 目标保留。
