# 用同片图像特征估计各面积候选的边界像素占用率

此方案登记时正式 B 的外层分数尚未计算。只在折 0、1 拟合患者上，排除了各患者的原 U-Net 教师平均偏好 Dice 分别为 90.0314%、90.1918%。保持各教师的像素置信度顺序，用真实标注的面积决定前景个数时，得到 91.8701%、92.1274%。这是使用拟合真值的误差诊断，不能在验收时使用真实面积。同一诊断改为按已有 alpha 排序，即使知道真实面积也只有 85.15%、84.76%；因此本方案保留图像模型的像素置信度顺序。前一项条件 Dice 增益回归使用树模型和汇总的 SAM 特征，未晋级。此处改为学习各个置信度区间中前景标签的占用率，且只根据现有 LIDC 二值标注训练。

对每份面积秩，从当前预测等效半径出发，以 −4 至 +4 像素的 33 个等距半径偏移生成候选前景个数。按当前模型得分稳定排序，从前一候选到此候选新增的像素形成一组；第一组是最小候选的全部像素。给每组提供图像引导分数、原始 CT 强度及梯度、各面积秩的预测尺寸、候选位置，以及当前切片公开 SAM2.1 的三个尺度图像特征在这组像素上的均值。空组用最近的排序像素填充输入，该组对占用损失取零权重。只从内层拟合病例估计特征标准化参数。

小型一维卷积网络预测每组的前景占用概率，同时估计该等级真实等效半径的残差。用占用概率估计候选前景集与真值的交集，再用估计真值面积计算 Dice 曲线近似，选择预计 Dice 最大的候选。训练包含组占用 BCE、半径 Huber 和曲线相对零偏移的拟合误差；所有监督均来自该折的拟合患者和真实折外教师预测。控制一为相同网络和种子，仅将公开图像特征置零，保留原 CT 与引导；控制二直接用完整模型预测的半径。固定四折全数报告，每组训练 1800 步、批量 16、患者和切片等权混合抽样。原检查患者以正式 A 的连续引导为输入；库患者分别选择 0、0.25、0.5、0.75、1 的修正强度，强度为 0 时必须完整重现参照二值掩膜。

主要比较为使用全部图像特征的占用率决策与正式 A 的内层参照。全部四折预测锁定后一起评分。仅当四折平均提高至少 0.05 个百分点且至少三折提高时，才进一步验证。若正式 B 建立了更强的外层参照，仍需在其对应内层引导上另行验证才考虑原外层复评。只允许原 CT 图块和从该图块算出的预测与公共视觉特征，不使用相邻切片、alpha、患者身份、真实面积或外部医学监督。四折原外层 0.910000 目标不变。
