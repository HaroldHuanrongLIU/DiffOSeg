The target remains at least 0.910000 on the original four patient folds. Test whether a larger general-image segmentation representation improves prediction while restricting medical annotations to existing LIDC cases.

Adapt absolute positional embeddings to 512 pixels as in the paired ViT-B study. Use the matching public prompt encoder, mask decoder and convolutional neck. Record the additional parameters and compute.

Reuse the same four rotations and CT windows. Cache the first 28 image blocks and the complete public image embeddings in the same label-free pass. Check a split forward against full inference and measure float16 cache quantization. First train the prompt decoder for 5000 updates on the original patient-excluded inner guides, with the same objective, batch 12 and seeds 50171+fold. Then tune the final four image blocks, neck and trained decoder for 5000 updates with the same objective, sampling, seeds 60171+fold, learning rates and EMA as the ViT-B adapted tail. Use the native CT as the only inference input and the guide derived from that image. Keep the simple four-preference decoder for this size comparison. Run engineering smoke before the four inner fits.

Within each fold, fit a single mixture with the original incumbent on library patients and then score the separate check patients. Prespecify the adapted ViT-H as the primary candidate and the frozen-encoder warm decoder as a control. Compare both to ViT-B and to the fold-local model selected for the accepted outer report. Keep all four outcomes and record actual compute, dataset, public weights, models, source and predictions. These are repeated-cohort inner measurements. Any later outer evaluation requires a separate fold-local lock and independent scoring.
