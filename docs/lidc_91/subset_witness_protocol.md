# 用互补拟合患者的预测判断分歧块

此前直接平均患者子集模型使整图 Dice 下降，但那项试验没有判断子集模型能否为主模型分歧的位置提供信息。检验原折 0、1 拟合患者。以患者排除的一级与二级教师等权提示 Q 为起点，只有两教师二值决策相反的同方向四连通块允许整块翻转。在上游共同排除的组 C 上，取两个分别只用 A、B 患者训练的模型在 C 的真实同片预测。严格验证两个模型都排除 C，且训练患者不重叠。

三组共用相同的块几何、原始模型置信度、原生 CT 和冻结 Hiera 局部图像特征。基础控制只使用这些信息；均值控制添加两份辅助 logits 的均值，主方法还使用两者在分歧块的共识和差异。辅助信息对模型互换对称，按块平均。用每个训练块翻转后的精确 Dice 变化训练效用回归，按块大小/当前预测面积和患者/图块等权加权。三组回归器固定 80 轮、最多 12 叶、每叶至少 40 块，学习率 0.06、L2 为 8，按固定归一化效用阈值 0.05 翻转。所有像素均来自当前 CT 的模型预测，拟合数据只提供校正器的参数。对三个上游留出组各自再做三分患者盲测。两折全部封存后使用原标注独立复算，另报告直接按两辅助模型同时反对当前标签才翻转的无拟合控制。只有主方法两折都提高、相对 Q 平均至少 +0.08 个百分点，且比基础、均值控制各高至少 +0.02 个百分点才扩展到内层 E。正式目标仍为原患者单片四折 Dice_mean ≥0.910000。
