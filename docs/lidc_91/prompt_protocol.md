# Automatic single-image prompts and a frozen general-image encoder

Use the original Segment Anything ViT-B (Meta source commit dca509fe793f601edb92606367a655c15ac00fdf; official checkpoint ec2df62732614e57411cdcf32a23ffdf28910380d03139ee0f4fcbe91eb8c912). This is the original general-image model, not a medically supervised SAM model. The only medical annotations used in this experiment are the existing LIDC training masks. Adapt positional embeddings to a 512-pixel registered single-slice view so that the official decoder's four-times upsampling returns the native 128 grid. Cache frozen features per image for four independent rotations/CT windows. This deterministic, per-image step has no label input, no multi-image statistics and no training. A case is only assigned to a fitting/check set using the frozen patient manifest.

Fine-tune the prompt encoder and decoder from the public weights on genuine OOF segmentation guides, with a small CT/decoder-feature detail path. Produce all four ranks in one pass. Prompts are boxes and soft mask estimates derived from the CT-only guide. Perturb boxes and masks during training; no human/test-target prompts. Train 5000 fixed decoder updates, batch 12, final EMA, patient-balanced sampling. Check first using the exact prior inner split and strong frozen incumbent as the deployment guide. Report standalone/control/fusion check values and do not report 91% based on any inner or prompted-with-truth run. The threshold for the frozen four-fold preference endpoint remains 0.91000.
