# 已有读片属性是否有助于预测面积秩误差

先问一个只用拟合患者就能回答的问题。以两个患者排除教师的等权连续预测为起点，加入存档的读片属性后，能否比只看图像和预测形状更好地校正四个面积秩的大小？已有属性包含纹理、边缘、球形度、分叶、毛刺、显著度和恶性程度主观评分。只对每项有效的 1–5 级评分求均值、标准差、有效比例，原始记录与四个掩膜没有可核验的一一对应关系。真实属性进入诊断模型时需要额外信息，诊断成绩不能作为内层或外层分割结果。

只对原拟合折 0、1 的已验证一级和二级教师银行执行。每折内三个原教师留出组分别按患者再分三份；每个拟合图块只由排除其整个患者的校正器和上游教师预测一次。只在同一原教师留出组内训练校正器，以免上游间接使用接受评分的患者。比较起始提示、图像与形状岭回归、同样输入加读片属性岭回归。图像特征包括现有两教师和均值提示的各秩半径、两者分歧及当前 CT 在预测轮廓内外的灰度统计。每秩训练目标为真实与原提示面积等效半径差，截断至 ±3 原生像素。输入用本次回归的训练患者加权均值与标准差规范化，L2 系数 30，患者与图块各半权重。推理固定应用回归偏移的一半，用均值提示的像素置信度排序取目标面积，零偏移精确重放原掩膜。

预先设定进一步训练 CT-only 学生的前提：相对图像形状控制两折均正且平均至少 +0.05 个百分点，主要诊断相对原提示也须平均提高至少 +0.05 个百分点。诊断扩展仍必须将真实属性全部从推理路径移除，另行验证可部署学生。若条件未满足，保留诊断并停止该路线。报告患者分组、属性覆盖与原始面积排序 Dice 复算。
