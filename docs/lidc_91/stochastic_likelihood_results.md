# 空间相关logistic-normal似然：拟合患者机制诊断

2026-11-07。**高精度版本通过机制诊断，但尚无新的患者检查或正式Dice结果。** 正式E仍为90.520974%，91%目标未完成。

本轮固定原折0的32名拟合患者，每人选一张原单片，采用真实患者排除OOF预测作冻结均值。只训练CT+guide条件的协方差头：每个面积秩独立的五维低秩因子，加正对角噪声。256步、batch8、四旋转；全部医学标注仍为现有LIDC。对照将**同一个已训练头**的协方差对角化，保留相同均值和每像素方差，因此改变的只有空间相关性。

训练目标先对每份整张二元掩膜求log-probability之和，再对共享潜变量作logsumexp积分。独立高斯噪声用Gauss–Hermite条件积分消去，采用Rao–Blackwell估计；四秩不作softmax、不混为一个panel。表中NLL是整掩膜负对数似然除以16384后再对病例/秩平均，越低越好。它不是Dice。[SSN原论文](https://arxiv.org/abs/2006.06015) · [机制研究及下一阶段建议](stochastic_field_research.md)

均值完全冻结。对称Gaussian噪声不会改变每像素边际概率相对.5的符号，因此单纯阈值输出仍是原均值掩膜。未来的实际收益必须由明确的联合决策或另行研究的均值适配产生，并在原患者验证口径下确认。

## 数值修订与独立证据

原版训练GH16、评估GH32没有达到逐像素精度。独立审查还发现其对角GH64/128检查只比较了像素平均值；补充审计的真实最大逐像素差为.002159，明显大于原平均差。旧模型、原报告和补充审计均保存在旧目录，未覆盖。

修正版保持完全相同的初始化张量、32病例、batch/旋转序列、随机种子、模型参数化和256步，仅提高积分精度并用分块重计算控制显存。训练/评估使用GH128，条件积分GH128/256的最大逐像素差为2.08e-06；对角化使用GH256/512，最大逐像素差为8.52e-06，均低于1e-5。

独立审计重新计算两组采样的稳定求和、ESS和最大权重，重载权重逐值重放2个病例各256次；另对最大方差位置作36次自适应一维积分，最大log-probability误差为8.37e-06（条件项）和8.07e-08（对角项）。数学测试验证整掩膜联合概率、20组解析积分对照、数值梯度、协方差、真正Bernoulli标签采样，以及分块前后的值/梯度一致。F采用小非零初始值；完全零F会在antithetic积分下产生近零梯度。
