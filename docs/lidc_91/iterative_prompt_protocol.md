# 同片反馈提示的两次解码

训练患者的真实折外 U-Net 引导在折 0、1 分别有 953、966 例，四偏好 Dice 为 90.0314%、90.1918%。推理时的单片参考分割由已经训练好的模型产生。已有固定 SAM2.1 金字塔只在一次提示和解码后输出。检验让解码器训练并使用自己的中间预测作为第二个提示，能否改善较好的初始轮廓。以同一 CT 的已有结果更新自动提示，整个流程只使用原切片。

冻结相同图像编码器。两组成对使用相同的公开 SAM2.1 完整金字塔、四个面积秩标注、折外训练引导及一个权重共享的提示解码器。每步都运行两次解码，第一次在无梯度模式，第二次按既有原生掩膜、原始解码掩膜和半径损失监督。控制两次都使用训练图块原引导。候选第二次用原引导与第一次预测各半的连续 logits，保留相同的随机提示扰动。首个提示和推理特征在两组相同。两组均从公开权重开始训练 5000 步，种子为 80171+fold，批量 12，原优化器、EMA 和四视角推理相同。推理时也两次解码；另将已经训练的控制模型按同一反馈规则推理，单列检验只改推理提示的作用。所有推理都从当前图块的冻结正式模型引导开始，不使用检查图块的真实掩膜。

原折 0、1 作为已使用的内层开发折，两组校准权重仍各自在库患者按相同五个权重锁定。预定主要候选为训练和推理都使用反馈，两次普通解码为直接对照。仅当两折平均相对正式内层参照提高至少 0.05 个百分点、相对同预算控制提高至少 0.03 个百分点，并且任一折相对正式参照下滑不超过 0.05 个百分点，才在另外两个开发折复验。保留患者配对区间、独立按集合交集重算结果以及额外推理成本。包括推理控制在内的选择均在读取独立检查分数之前锁定。四折正式目标仍是原始测量口径的 0.910000。
