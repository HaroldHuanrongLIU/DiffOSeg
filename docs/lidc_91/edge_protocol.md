# Native CT boundary-posterior study

Use patient-cross-fitted segmentation probabilities from the inner training patients, never in-sample scores, to learn the probability of a true foreground pixel in a narrow contour band. At a native pixel combine the registered CT, estimates of local foreground and exterior intensity means/variances at three spatial scales, normal-direction profile, mask distances, rater rank and initial probability. All spatial statistics are computed on one CT slice and its image-produced masks. A histogram gradient booster learns rater-specific (rank as feature) posterior inclusion in this band; calibration of the final logit blend and expected-area update uses the library patients, and the separate check patients are held out. Train no model on test masks and do not substitute true areas. This branch tests whether physically localized density can explain the previous equivalent-radius oracle gap. Record raw branch, blends, radius error and paired four-fold check before any application to outer data.
