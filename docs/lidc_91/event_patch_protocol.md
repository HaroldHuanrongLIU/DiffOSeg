# 高风险位置的单片空间残差预测

严格排除患者的已有事件概率，在每例四秩一致边界上取最高 20% 的位置，两拟合折捕获约 49.6% 的真实错误事件；直接采用辅助教师一致反对的标签仍使 Dice 下降。现在固定上述位置，训练专门预测当前四秩 logits 的局部残差。仅在同一原上游留出组中的另外两份拟合患者训练，评分病例和其余切片均被所有模型排除。校正器训练时不使用任何事件概率或由其他子折计算的风险选点，以防通过评分患者间接泄露。

取当前注册 CT 的四通道强度/梯度、两教师的四秩 logits 及单片公开 Hiera 的 32 个原生特征。在一致边界的原生像素上采 7×7 邻域。两组具有相同的三层 3×3 卷积（32、32、24 个输出通道）和 4 个秩输出；对照将中心像素重复到整个邻域，主方法用真实空间邻域。最后线性层为零，初始输出精确重放 Q。每个子拟合固定 700 步、每步 192 个中心像素，按训练病例/患者等权混合抽病例，然后在其一致边界中均匀抽像素。加权 BCE 监督原四份标签，按各秩预测前景面积倒数加权；网络在 Q 上施加最多 ±4 logits 的有界修正，并以 0.015 乘加权平方修正作惩罚。AdamW，学习率 0.0005、末步收敛至 5%，固定 EMA。两组使用相同种子、初始化、图块和位置，任何待评分病例的标签仅用于最终独立计分。

主要选择仅在既有事件风险最高的 20% 位置采用空间模型的正负号。控制一在完全相同位置使用中心重复模型；控制二保持同一个空间模型，改按原四秩最弱 logit 幅度取预算；另报告空间模型在全部允许位置的输出。嵌套的九个患者留出批次必须与冻结事件头的原始拟合/留出患者完全一致。两折封存后统一按原始面积排序标注复算。要求主方法相对起始提示两折均正、均值至少 +0.08 个百分点，并比两个匹配控制各平均高至少 +0.02 个百分点，才继续到内层 E。0.910000 的原单片四折正式验收要求保留。
