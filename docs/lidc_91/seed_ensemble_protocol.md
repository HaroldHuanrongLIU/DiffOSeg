# 独立初始化的异构单片模型组合，四折内层复验

正式模型由原 DiffOSeg 单片修正与 SAM ViT-B 偏好分支组成，当前原四折 Dice_mean 为 0.9045313485402589。在已检查的折 0、1，多个冻结 SAM2.1 Hiera-Tiny 解码实验相对这一参照均出现正向平均点差，粗细特征、附加门控、重复提示及训练时刻的独立增益较小，也存在折间差异。这些先前的机制实验各自按已登记门槛结束。本试验检验一个新的整体模型组合，在未被前述 SAM2 试验用于形成假设的内层折 2、3 独立复验；原四个患者折全数报告。先前的两折属于开发证据。

各折统一使用原公开 SAM2.1 图像模块的完整三级金字塔、单次普通提示及原最终 5000 步 EMA，不再选择特征层、训练时刻或反馈方式。训练三份相同结构的提示解码器，种子为 50171+fold、67171+fold、84171+fold，均用本折真实患者折外引导和同一批符合范围的 LIDC 训练病例。折 0、1 的第一种子直接复用可核验的最初固定金字塔拟合和预测，保留其最早结果；其余成员独立训练。推理时在同一原生 CT 上得到正式参照的单片引导，用各成员预测四种面积偏好，先把三份模型的连续 logits 等权平均，再在该折库患者的原五个权重中锁定与正式模型的融合权重。报告第一种子及另外两个单成员的同规则消融。无临床标注、面积真值、患者身份或邻片参与推理；新增通用预训练和三次解码的代价单列。

将所有四折、所有成员的库内选择和二值预测封存后，再一次算四折内层检查分数；每折仍只使用本折库患者决定权重。正文主指标为三模型组合对正式方法参照的四折等权 Dice 增量。只有四折增量至少 +0.05 个百分点、未用于形成假设的折 2 和 3 各自均为正、且这两折的平均增量至少 +0.05 个百分点时，才推进独立的原四折外层实验。比较独立种子是否额外优于单成员是消融问题，分别报告，不事后替代主要候选。另从患者和原掩膜独立复算，报告分层患者配对 95% 区间。所有模型权重和选择锁定身份保留。四折验收仍以原 214 位患者、1609 个图块的未舍入 Dice_mean 至少 0.910000 判定。

为统一三成员的存储精度，组合在三个成员都已转为 float16 保存的连续 logits 上以 float32 执行等权平均。折 0、1 既有第一种子的单成员消融直接保留其原先选定的二值掩膜。其余成员也先从实际 float32 输出锁定单成员掩膜，再保存半精度连续输出；四折检查患者不参与上述决定。
