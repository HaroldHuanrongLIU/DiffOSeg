The aligned U-Net was trained against labels linearly sampled from the native mask; its usual inference pulls logits back and averages them. Test the actual forward operator instead. For each known affine image view, infer logits on the current CT only. Fit the mapping from per-view logits to expected interpolated labels only on library patients. Construct the exact adjoint and nine-point normal matrix of bilinear sampling on the native grid. Estimate native occupancy by regularized inversion and by binary coordinate updates, with an image-prior term and optional contrast-weighted neighbor cost. This is a deterministic inverse resampling estimator on repeated views of the same image; it does not create independent clinical observations.

Use integer dihedrals, subpixel translations and a small set of fixed scales/angles about the image-derived center. Inferring positions are never derived from test masks. Calibrate observation temperature/bias per rank and reconstruction regularization on library patients, with checks on the separate patients.
