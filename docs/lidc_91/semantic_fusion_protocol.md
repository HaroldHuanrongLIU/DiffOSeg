# 在同一 CT 的 SAM 解码器中融合自监督视觉表征

历史 DINOv2 试验将其与独立 U-Net 共同训练。这里固定正式 E 的基础提示、三个图像种子及 0.25 的新增分支权重，检验在 SAM2.1 提示解码前，通用自监督视觉表征能否补充其图像金字塔。仅使用当前 LIDC CT 与已有医学标注。使用已核验通用 DINOv2-S/14 权重，冻结全部编码参数。与 E 同一训练折注册和按图归一化后，以 448×448 输入得到 32×32、384 通道的末层 token 图。等容量对照使用 E 自己的 32×32、256 通道粗层。

每原折仅以该内层拟合患者当前图像旋转 0 的 token 拟合 PCA。每图使用中心和全图的等距采样，各 64 个位置；分别对 Hiera 粗特征和 DINO 特征取 64 个主成分并按各自拟合方差白化，投影截断至 ±6。检查及库患者只使用冻结投影。两组都将 64 通道经 1×1 卷积、48 个 SiLU 隐单元和零初始化 1×1 输出加到 Hiera 的粗层，使用相同金字塔跳接和提示解码器。新参数的创建保持原种子随机流。原训练患者、真实一级 OOF 提示、5000 步、EMA、三种子、四个既有旋转和当前 CT 的原生细节均沿用 E。

在原内层折 0、1 先锁定所有掩膜。三项比较为 E、Hiera 自身粗层投影的等容量控制、自监督 DINO 投影的主要候选。原 E 二值掩膜按原文件保障身份。全部封存后计分，同时用原始面积排序掩膜进行独立逐项复算。扩展要求主要方法在两折均超过 E、等权平均至少 +0.05 个百分点，且平均超过等容量控制至少 +0.02 个百分点。若未通过则关闭该假设。若通过再单独冻结其他内层折的复验，最后才可考虑正式四折。测试冻结模型初始输出、残差梯度和拟合 PCA 的范围与白化。
