# 在自监督视觉编码器内部学习任务相关注意力

此前 DINOv2-Small 的冻结语义图与 Hiera 粗层融合在两折有 +0.0421 个百分点的增量，未达到其门槛。直接用冻结 Large 特征解码完整掩膜也未胜 E。此处检验不同机制：LIDC 的分割监督能否使 Large 的最后一个图像注意力层在当前 CT 内建立更合适的位置对应关系？只使用已有公开 DINOv2-Large 权重（SHA-256 为 8320e4778a7f8850d10f30d97e9138438e1851af1576fea789c43746140cc655）、SAM2.1 和当前 LIDC 四份掩膜。

以原折 2、3 做首轮内层对照，与最初 DINO 小模型假设形成的折 0、1 分开报告，队列仍为历史重复使用。每个 CT 独立注册并采用 E 的四视角全图归一化，输入 DINO 尺寸 224 得到 16×16 个原生 patch tokens。固定前 23 层并以单图前向缓存最后一层的输入（包括分类 token），无批间统计或医学标签。检查打包/解包及最后一层重放相对公开完整单图输出的误差，容许相对 L2 不超过 0.025。

主方法仅对最后一层的 query 和 value 两个投影各加入秩 8 无偏置的低秩更新。等容量控制冻结同一层，在公开最后层输出上增加两组相同维数的逐 token 低秩更新。每组新增 32768 个与本问题相关的适配参数，第二个线性投影初始化为零。两组都把末层图像 token 标准化后，经 1024→48→256 的空间投影、双线性上采样加到 SAM2.1 粗层；输出投影也从零开始。因此初始分割损失应重放原 E。公共 DINO 其他参数冻结。医学监督仅来自当前折拟合患者，网络推理只读取当前 CT。

三原种子每组各训练 5000 步、批量 12，采用与 E 匹配的折外教师引导、原监督、EMA、四旋转预测和固定 0.25 图像分支权重。必须核对新增两组低秩参数都实际更新。先锁定两折全部原生掩膜再评分。主方法两折均高于 E、平均至少 +0.05 个百分点，且相对等容量输出端控制平均至少 +0.02 个百分点，才登记其余两折确认。原 214 位患者、1609 张单片的正式四折 Dice_mean ≥0.910000 才验收。
