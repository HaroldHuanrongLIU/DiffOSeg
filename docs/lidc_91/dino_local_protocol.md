# 独立自监督编码器的结节局部特征探测

方向性 CT 强度修正的拟合盲测未通过。改为检验单片结节周围的自监督视觉特征：在同一原生边界处，固定局部视野能否比同片全图提供额外的可预测信息？使用通用自监督 DINOv2 ViT-L/14，固定官方 facebook/dinov2-large 修订 47b73eefe95e8d44ec3623f8890bd894b6ea2d6c，权重 pytorch_model.bin 的 SHA-256 为 8320e4778a7f8850d10f30d97e9138438e1851af1576fea789c43746140cc655。权重只读加载，使用已有项目环境，新临床监督只含当前折 LIDC 的四份标注。[模型来源](https://huggingface.co/facebook/dinov2-large)

第一步在两个原折的拟合患者进行患者留出像素探测。用已验证两级患者排除教师均值的多数预测中心定位本图块，若为空则用图块中心。两种视图都以该中心取样，边长分别为固定的 128 和 64 原生像素，双线性缩放到 448×448，再使用同一三通道灰度归一化。局部与全图共享同一冻结编码器，取最后一层的 32×32 patch tokens。使用固定种子 39117 的 1024×64 高斯投影，缩放因子 1/8，使特征压缩不依赖其他患者。将对应位置的投影特征双线性拉回原生网格，局部视野之外退回全图。同一模型的两种视图具有相同参数与相同特征维数。

拟合全部保持原三组教师的患者排除范围，并在每组内再按患者三分；对距当前轮廓不超过 2.5 像素的四秩区域，比较加入全图或局部特征的概率残差回归器。保留相同 CT 强度、教师分歧、秩和距离特征。相同 70 步、9 叶、最小叶 80、L2 为 10，学习率 0.07 的梯度提升器拟合二值标签减现有概率的残差，以固定强度 0.75 修正。只有局部特征相对起始提示在两折都提高、平均 +0.08 个百分点以上，且比全图同编码器平均至少 +0.02 个百分点，才进入内层 E 检查。另从原始面积排序标签独立复算。训练折外图块、邻片和额外医院数据均不参与拟合。正式验收为原单片患者四折未舍入 Dice_mean ≥0.910000。
