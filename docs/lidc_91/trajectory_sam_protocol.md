# 同一患者训练轨迹上的时间平均

固定 SAM2.1 图像金字塔已经完成两折内层试验。折 0 的粗特征模型从 5000 步继续到 10000 步后，独立分支在库患者由 90.0851% 降至 89.9270%，检查患者由 89.9083% 降至 89.6622%。这两个时间点提示训练阶段可能影响偏好边界。用新的成对实验检验一条训练轨迹上的多个预测能否改善独立患者结果。先前模型、观察与改变假设的时间均保留。

使用固定的 SAM2.1 完整金字塔、当前单片、原 LIDC 拟合患者及真实折外引导，重复其原 5000 步、初始化、批量和种子。额外保存第 1000、2000、3000、4000、5000 步的 EMA 解码器。主要候选为五个模型的原生四旋转 logits 等权平均，之后仅一次与已有单片参照按库患者选择的权重融合。匹配控制为本次轨迹最后的 5000 步。另报告仅用库分数选取一个早停时刻的控制，如库分数并列选较早时刻。库内各自用原五个融合权重，之后在另组检查患者上评分。记录每个时刻的独立分支曲线和融合结果；主要结论只由事前确定的五点平均决定。

先跑原折 0、1，两个折此前已用于形成假设。若两折平均相对正式内层参照提高至少 0.05 个百分点，并且两折分别高于同轨迹最后一步融合，才扩展到未用于本假设的折 2、3。批量、EMA、患者划分、图像与标注口径均不因选取时间改变。实现须证明保存快照不改变同一次训练中最后那个模型的参数身份，所有时间点的掩膜选择先锁定后评分，最后从掩膜独立核验。图像编码器固定并可共享，解码器推理次数增加至五次。此阶段不读取新外层标签。原四折验收阈值仍为 0.910000。
