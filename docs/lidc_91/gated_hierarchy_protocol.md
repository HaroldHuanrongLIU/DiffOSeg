# 粗分支热启动后的局部细节门控

固定 SAM2.1 图像金字塔在折 0、1 的内层都超过正式图像参照，但相对相同骨干的低分辨率控制，两折分别为 −0.033406 和 +0.139530 个百分点。其原定双折同胜门槛未通过，本试验作为根据此次观察提出的新假设记录。

从各折已完成 5000 步的低分辨率 SAM2.1 解码器热启动，追加 5000 步。在候选中，用局部预测不确定性、估计前景比例、CT 与局部均值之差和 CT 梯度幅度预测两张门控图，分别调节原有高分辨率特征的贡献。使用带 tanh 的 1×1 卷积（十个参数），权重和偏置从零开始。每处权重允许在 −1 和 +1 之间变化。控制组由完全相同的热启动继续训练相同步数，始终关闭两层细节。训练病人、折外引导、EMA、每批 12、权重衰减、0.00016 峰值的原调度继续匹配，追加训练采用与首段不同且配对的新 RNG 种子。两组追加训练第一步的损失须相等，并验证门控有非零梯度。推理使用已有正式模型从当前单片产生的自动引导和公开的图像特征。单独报告条件化融合与沿用原方法的结果。

先只做原折 0、1 的两个成对试验，两折此前均用于提出假设。候选必须在两折都超过同初始化、同追加预算的对照，同时相对正式方法对应的内层参照平均提高至少 0.05 个百分点，才按原设置在后两折进行额外内层验证。每折仍先按库患者锁定原五个融合权重，在独立检查患者评分并复算全部掩膜。此方案不改变已报告的固定金字塔试验和其门槛。不根据外层分数调整设置。原四折外层目标仍为未舍入 Dice_mean ≥ 0.910000。
