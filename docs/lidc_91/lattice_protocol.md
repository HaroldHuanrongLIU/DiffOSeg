# Native-lattice rank specialist, single CT

The previous successful registered network was trained and sampled mostly after continuous interpolation. Test whether native-pixel edge supervision and separate rank-conditioned decoders can improve contour precision without changing acquisition inputs. Start from the matching frozen registered model. Train two paths: exact lattice rotations/reflections and integer translations about the original crop convention; a smaller fraction of continuously transformed context examples. Keep registration before either augmentation. Add learnable rank-conditioned residual logits using fine image features, neighboring native CT intensity differences, and a pooled image-specific expert descriptor. Include a hard-forward aligned Dice/area loss with a differentiable probability approximation; keep soft Dice and auxiliary vote supervision for stability. The encoder and original calibrated head remain trainable at a lower rate, and new residual layers start at zero. Use fixed 6000 optimizer updates, patient-balanced batches, final EMA and eight native dihedral views. All label-derived geometry is restricted to training data. At inference use only the known image-only locator; the exact transforms use rounded predicted offsets.

Only use training-patient splits to choose between original and native predictions or to learn a bounded area correction. Seal a design before any independent outer scoring and retain evidence if inner improvement is inadequate.

## Separate pixel order from target area

Add a shape loss that fixes the foreground pixel count of each training prediction to that training rater's area. Optimize its native hard Dice using a smooth cardinality projection with its constant-mass gradient (remove the common logit-shift direction). This is training-only supervision; predict the four radii from the same CT and image features at deployment, and always compare ordinary thresholded predictions. Fit the radius correction on deliberately varied image-predicted support areas to reduce in-sample area bias. Use local fixed-grid CT evidence and context-conditioned rank-specific readouts. Check the exact integer-count forward and the analytical gradient. Fit blend and radius trust only on library patients. Report an ordinary thresholded-control, the effect of supplying only image-predicted areas, and training-only true-area upper bounds if useful.
