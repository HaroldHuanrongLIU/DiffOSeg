# Predicting which contour is correct at disagreement pixels

The adapted SAM and incumbent now have four complete inner checks. An explicitly unavailable-at-inference diagnostic used actual check labels to choose convex-combination weights. A single weight per case has a four-fold diagnostic ceiling near 91.00%; allowing individual pixels to choose gives more headroom. This motivates a deployable disagreement classifier.

Freeze both models. Use the incumbent masks and adapted SAM logits already saved after single-slice inference. On pixels where their hard predictions differ, train a classifier to predict whether the SAM prediction matches the annotation. Agreement pixels retain the common prediction. Supervision is restricted to the current fold's library patients. Train both a score-only control and a contextual candidate with identical histogram gradient-boosting settings. The contextual candidate adds registered single-slice CT intensity and local contrast, predicted contour distance, relative area, component support and position relative to the image-predicted region. Use patient- and area-weighted observations to approximate the case/rank Dice objective. Fit 100 iterations, 0.05 learning rate, seven leaves, at least 80 samples per leaf, L2 regularization 15, and fixed seed 88171+fold. When the estimated probability of choosing SAM lies between 0.4 and 0.6, retain the previously locked scalar blend's decision. The contextual candidate is the prespecified primary candidate; report the score-only control irrespective of outcome.

Fit and save both classifiers before scoring checked patients. No case IDs, medical metadata, adjacent images or reference masks are prediction features. Report per-fold results, the frozen scalar and incumbent comparisons, all negative findings, and agreement-pixel preservation. Oracle weights never enter candidate prediction. The unchanged outer four-fold acceptance threshold remains 0.910000.
