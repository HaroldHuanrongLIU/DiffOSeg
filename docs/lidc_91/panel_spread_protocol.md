# 四秩轮廓相对共同边界的离散度校准

先在原内层折 0、1 的拟合患者检验一个病例级决策。起始概率取已有、经患者来源核验的两级教师平均 logits。用此前固定的亚像素距离表示四份预测，局部四秩距离共享其算术均值。以一个全病例系数缩放各秩距共享值的偏差；系数 1 必须精确恢复起始掩膜。只修改原轮廓内外三像素，限制每秩修正至 ±2 像素。这种变换允许局部交叉，整例的唯一动作是改变原预测的秩间间隔。

各候选动作按 1、0.875、1.125、0.75、1.25、0.5、1.5、2 的次序处理并列。定义离散度为六对面积秩的对称差像素数平均，除以本病例原预测四秩的平均格边周长；所有动作都用同一分母。拟合目标为真实 panel 离散度减原预测离散度，截断于 ±3 像素。主方法按两教师与起始掩膜的半径、分歧像素比例、三者离散度和各秩边界内外 CT 统计作标准化岭回归，L2 系数 30。控制分别为同样模型去掉 CT 统计，以及拟合患者的加权均值。患者等权与图块等权各半。预测时用一半的估计变化，以与此目标离散度最接近的候选掩膜作为输出。另报告用真实离散度或真实逐例最优 Dice 选择动作仅能达到的拟合诊断，不把这两个结果用于模型选择或部署。

每折三个上游留出组分别再按患者三分，回归器和两级教师全部排除接受评分的患者。两个原折的全部掩膜均封存后独立从四份原始标注计分。只有主方法在两折均提高、平均比起始提示至少 +0.08 个百分点、相对几何控制与均值控制各高至少 +0.02 个百分点，才扩展到真实内层 E。最终仍按 214 位患者原单片四折未舍入 Dice_mean ≥0.910000 验收。
