# Image-conditioned reset distribution in categorical preference diffusion

The accepted outer Dice is 0.9045313485402589. Test a change to the categorical corruption kernel of DiffOSeg in a fold-1 paired inner pilot. Compare a uniform Bernoulli reset probability of 0.5 with an image-conditioned reset probability of 0.02 + 0.96*sigmoid(guide). The same four single-slice guide logits enter both denoisers. Each rank is one binary state; a shared spatial network sees all four states. The original cosine schedule has 32 steps; set the final cumulative retention to zero so the declared terminal law is exact.

For clean bit y, cumulative retention a and reset probability p, the noisy bit is Bernoulli(a*y+(1-a)*p). For a reverse jump from t to s, use the exact binary transition probability conditional on each possible clean bit, then average the two posterior probabilities by the predicted clean probability. The clean logit combines the guide, the aligned U-Net, and the exact observation log-likelihood ratio for the sampled noisy bit. New guide/noise/time input weights start at zero. Train the network with uncertainty-weighted clean binary cross-entropy and reverse KL, a soft preference Dice loss, and the existing vote auxiliary loss. The uncertainty weights depend only on the guide. Use the same fold-specific aligned initialization, real patient-out-of-fit guides, 8000 updates, batch 16, seed 107071+fold, final EMA, and optimizer settings for both kernels. Use only the actual fitting patients and their existing annotations.

At inference use the same CT and its frozen guide. Run eight reverse jumps with 16 common antithetic noise samples, reuse the same noise bank for every image, and compute the empirical expected Dice of masks ordered by their mean final foreground probability. Select the best foreground prefix under that empirical distribution. Also report ordinary 0.5 posterior thresholding. No reference annotation enters the sampler or decision. Fit the same five blend weights with the accepted image-only guide on library patients and score the distinct check patients. The image-conditioned kernel is the primary candidate, and the uniform kernel is its preregistered control. This is a finite-budget conditional diffusion refiner, with additional sampling cost.

The method extends the repository's uniform categorical transition in ddpm/models/diffusion_denoising.py. The paired study uses the original cosine scheduler and tests the uniform special case against DiffusionModel.theta_post_prob.
