# Adapting early image attention on the current LIDC slice

The accepted outer mean is 0.9045313485402589. Increasing the original SAM backbone to ViT-H gave an inner mean of 0.9053650584578452 against 0.9054114844413168 for the accepted method. A late native CT residual also had a small mean effect. Test whether directly adapting the early image representation is more effective than increasing frozen capacity.

Run matched original SA-1B ViT-B continuations on inner folds 0 and 1. Both arms evaluate the original 512-pixel image encoder online, then fine-tune its last four blocks, neck and warm 5000-update prompt decoder exactly as in the adapted-tail study. The control freezes the first eight blocks. The candidate adds rank-8 residual updates to the query and value projections in each of those eight blocks. Keep pretrained weights and keys frozen, initialize the up projections to zero, use scaling one, and isolate random initialization from the paired sampling stream. The additional 196608 trainable parameters use learning rate 0.00012 and weight decay 0.0002. Keep batch 12, 5000 updates, the previous rate schedules, guide augmentation, losses, final EMA and four-view prediction. Both arms recompute the same prefix online and round it to float16 before the adapted tail. Record the extra backward computation and observed GPU time.

Use only existing LIDC fitting masks and patient-out-of-fit training guides. For fold 0 use the matched Lakers warm initialization. For fold 1 use the completed E11 ordinary SAM decoder trained on the same eligible fitting patients and the E11 OOF bank. Verify its patient list, public weights, budget and checkpoint identity. Within each fold check zero initial attention updates, nonzero gradients, and paired first-loss agreement. Choose the usual five fusion weights with the frozen image guide on that fold's library patients and score only its separate check patients. Compare to the actual inner selection behind the accepted complete outer report. Keep all outcomes. A new original four-fold result would require its own fold-local lock.

This experiment adopts low-rank attention adaptation as in [LoRA](https://arxiv.org/abs/2106.09685) and the SAM adaptation direction in [SAMed](https://arxiv.org/abs/2304.13785). It initializes from the original general-image checkpoint and trains the new medical parameters on LIDC only.
