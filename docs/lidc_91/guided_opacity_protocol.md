# 单片局部线性引导的轮廓修正

锐度响应诊断显示，直接平均对原提示的改动范围很小。本实验直接在患者排除教师给出的轮廓内外 3 个原生像素寻找能由本图 CT 强度解释的边界偏移。采用 [引导图像滤波的局部线性模型](https://people.csail.mit.edu/kaiming/eccv10/index.html)。原内层折 0、1 的拟合患者起始概率为两教师等权 logits 的 sigmoid。使用各教师在其许可训练患者上估计的整数配准，X 为当前注册 CT 的存档灰度除以 255。对每个面积秩独立操作，以 9×9 窗口和置信权重 0.1+0.9(2p−1)² 估计当前概率 p 对 X 的加权线性拟合；斜率分母加 (12/255)²。取覆盖像素的全部窗口的系数均值，得到引导预测 H。相同置信定义和窗口去掉斜率得到纯空间结果 S，边界使用镜像延拓。

主方法只把 CT 独有的残差 H−S 加到现有概率；第一控制加 H−p，第二控制加 S−p。固定在起始二值轮廓距离绝对值不超过 3 像素处修改，越过阈值后按实际二值掩膜打分。每个原教师留出组再分成三个互斥患者子集，仅在另外两个子集上从 0、0.25、0.5、1 选强度，零强度须逐位保留参考。每个图块的教师和强度选择都排除接受诊断的患者。先封存两折，再独立复算原始掩膜。只有主方法相对起始提示两折均正向、平均至少 +0.08 个百分点，且相对上述两个控制各至少 +0.02 个百分点才扩展到内层 E。此处不使用真实面积或真实 alpha 指导修正；最终验收需原 214 患者单 CT 四折 Dice_mean ≥0.910000。
