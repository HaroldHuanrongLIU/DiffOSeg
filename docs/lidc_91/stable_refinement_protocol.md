# 保留双种子轮廓信息的确定性精修

移除 v9 连续分支时，四折注册场和最终提示均通过独立进程的逐字节重放。四折检查变化为 +0.048468 个百分点，低于已登记的 +0.05 条件；折 2 选择零新增权重。更早的三种子连续组合在折 2 曾提高 +0.126907 个百分点，但其完整外层流程不能恢复旧连续张量。此处提出另一条算法：保留前一偏好模型提供的轮廓信息，在原来需要该信息的折上用确定的数值实现重算它。登记时正式 B 的任何新外层分数仍未打开。

保留前次配准、放大视野、A 图像模型和三个 SAM2 模型的输入输出结构。依原冻结折内权重，在配准全图的连续置信度中加入 v9 轮廓概率；其非零系数只出现在折 2。使用相同的两个已拟合边界精修器，由当前 CT 与中间票数区域计算欧氏距离引导。此距离由 CPU 的精确欧氏距离变换求得。两个精修器用 CPU float32、固定单线程、确定性运算进行八视角推理，按原权重与冻结的 v4 预测结合，再在 CPU float32 做联合解码，最后恢复原来的面积偏好连续分支。GPU 上的已核验图像组件继续使用确定性算子及固定 CUDA 矩阵乘工作区。在 v9 系数为零的折，直接沿用配准图像连续场的同一计算式。保持原 A 的已存档二值符号。以该流程产生的连续引导作为新的有版本预测文件，既保存完整张量，也保存哈希。各折两个独立进程均须逐字节重现注册连续场及最终提示。在折 2 还比较两个中间精修器的指纹。不能用事后选择某次旧重放的办法构造输入。

四折独立内层库锁定融合权重后统一评分。三种子完整模型为预定主方法；直接使用注册 CT 置信度为控制。保留原控制的既有结果，本轮重新按新协议运行。晋级条件：四折平均相对正式 A 的增量至少 +0.05 个百分点、至少三折为正、且折 2 和折 3 均为正，并满足所有确定性重放检查。先前的折与候选已用于探索，本次仍为同队列开发证据。若晋级，另行锁定所有正式推理条件，在原外层训练权重上重新生成四折全部预测并封存，独立复算后验收。仅输入当前 CT 和同图像产生的模型预测，医学标注只来自现有 LIDC。正式 91% 目标和原患者口径保持不变。
