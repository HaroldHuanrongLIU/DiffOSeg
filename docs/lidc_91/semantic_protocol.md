# Semantic area correction on the frozen single-slice protocol

Before any new outer evaluation, test whether general visual features can estimate individual rater extent beyond a registered contour. Initialize the native-resolution U-Net from the corresponding previously fitted registered preference model. Route intermediate tokens from a DINOv2 ViT-S/14 pretrained on LVD-142M (official facebook/dinov2-small, revision ed25f3a31f01632728cabb09d1542f84ab7b0056, PyTorch weights SHA-256 1051e25b2ed69ddad24f3c41e7b6eed6e7f7d012103ea227e47eb82e87dc2050) into three feature scales with initially zero residual adapters. Three intensity windows of the same registered CT are the only vision-transformer input channels. Early transformer blocks are frozen. Predict four ordered equivalent radii with an auxiliary image/feature-pooled head; use native radii in supervision and account for crop scale. Train using actual four masks, their cumulative vote supports and bounded intensity/scale augmentation. The expected benefit is better estimation of the patient-dependent extent at indistinct boundaries. No pretrained medical segmentation masks or additional subjects as supervised data.

Fixed initial pilot: 5000 optimizer updates, batch 12, EMA, matched fold-specific registered initialization. Use the inner-fit patients first. Choose image-logit ensemble fraction and optional radius correction on the existing library half, and require a 0.91000 fold-equal check mean before a formal target test. Record less successful internal results without scoring new outer labels. Always show baseline and standalone model. An oracle area diagnosis, external paper metric, retrospective arm or change of rater matching cannot establish this goal. Retain the CT-only inference interface and synchronize source to all authorized machines.
