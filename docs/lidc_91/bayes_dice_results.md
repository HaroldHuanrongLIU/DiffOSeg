# 面积相关经验Dice解码的库内筛查

2026-11-07。**候选族关闭，未打开检查患者评分，原外层NOT_RUN。** 正式E仍为90.520974%，本轮未达到91%。

具体方法采用General F-measure Maximizer：对每个候选输出面积k，用完整掩膜样本的面积修正逐像素期望贡献，重新选择top-k，再选经验期望Dice最大的k。匹配控制使用同一有限分布，固定边际概率顺序后精确选k。此前仓库的扩散前缀解码只有后者。该算法最大化给定经验银行的效用，不能把种子/旋转银行称为已校准的真实临床后验。[原始GFM论文](https://proceedings.neurips.cc/paper/2011/file/71ad16ad2c4d81f348082ff6c4b20768-Paper.pdf) · [事前研究](bayes_dice_research.md)

银行固定为E三个Hiera种子各四旋转的单视角二值输出，加原E最终掩膜，共13张同片、同秩预测。先完整重放原E：四旋转float32求和/4、成员转fp16、三成员fp32平均及原.25融合，四折库掩膜逐位相同。只使用现有LIDC医学标注和原单片输入，不训练新分割模型。

两列均为**读取库真值的诊断上界，不能部署，也不是正式分数**。第一列允许在全部样本的交集I与并集U之间自由选择，最优为I∪(真值∩U)，说明分歧范围较大。第二列只能在五个已由样本自身解码完成的GFM输出中选择；它未通过预设0.479026个百分点余量门槛。因此没有训练逐例选择器，也没有扩大alpha网格或更换样本源。

五个固定alpha为0、.25、.5、.75、1；E样本占alpha，其余12张均分剩余质量。即便各折按库平均选择最佳一个alpha，库内平均增量也仅0.003455个百分点，此数仍不是独立验证。相对固定前缀，GFM仅改变15份候选秩掩膜，经验效用差极小；对这组相关视图，面积相关重排没有提供足够新的决策空间。

验证：先以4096组小掩膜验证支持族oracle；GFM用32768次全候选比较、64个同面积银行及空/全前景、零权重、alpha端点、并列规则检验。合成全局反例为GFM .4、固定前缀11/30。独立审查发现的面积并列选择偏差在任何临床候选解码前修复，并新增旧实现会失败的回归；原测试收据保留。四折全部候选封存后才用库标注评分。从原四份面积排序掩膜独立复算22920项Dice，集合公式和向量计数一致；另核对480个有限银行期望效用，最大误差2.22e-16。全程没有把oracle输出用于检查或外测。
