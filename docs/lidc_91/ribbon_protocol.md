# Subpixel closed-contour ribbon expert, before new outer scores

Represent the boundary with 128 equidistant points on the largest continuous zero-level curve of the guide. An adjacent CT slice, case identifier and test annotation are prohibited inputs. Sample registered CT along the outward normals of this curve on a quarter-pixel radial grid. A periodic network regresses four individual normal offsets. Unlike polar rays from the lesion center, each ray originates on the local contour; the initial guide is a single-slice image prediction at deployment. Train with known contours and independently perturbed common guides on training cases only; use CT profile, normalized intensity, direction, curvature and guide geometry. Fit radial intersection/occupancy and an area loss based on the predicted polygon. Auxiliary true areas, signed distances and contour locations remain training-only. Keep the incumbent available outside the narrow editable contour region. Use scale-, angular-origin- and orientation-augmentation, fixed final EMA and balanced patient sampling. No special-case patient rules.

Dev stage: construct each outer fold's ribbon model using only the existing inner-fit patients (6000 updates, batch 40). Preserve the same reference dataset hash, single CT geometry, four area ranks, and unbiased reference scores. Use matched real image-derived guides on inner validation; the library half can choose a blending amount and the separated check half measures it. If appropriate use a fixed-budget replica trained on the complete outer train fold. Archive negative attempts. No new outer scores before locks. Report original order/fold-equal mean and interval, complete case pairing, patient disjointness, and raw-mask audit for a 91% claim.
