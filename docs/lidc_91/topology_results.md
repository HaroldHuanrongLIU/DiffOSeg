# 单切片几何对照结果

基于训练标注的连通性统计，检验了小连通区域过滤与限定面积的孔洞填补。每折由原内层库患者选择参数，再对独立的内层检查患者评分。四折均值从共同对照的 **90.419224%** 变为 **90.418734%**，本次规则没有带来净改善。

四折选择的前景组件过滤阈值均为零。孔洞填补上限依次为 16384、16384、0、16 原生像素。折 0、2 的检查均值相同，折 1、3 略降。该结果说明难例中观察到的额外区域，尚不能用这组简单规则稳定修正。
