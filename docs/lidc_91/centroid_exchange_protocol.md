# 同片四偏好掩膜的定面积边界交换

内层拟合病例的四标注平均质心在 [64,65] 的二维像素格内高度集中。初查折 0、1 的平均质心距拟合中心至多半像素的比例为 97.4%、97.7%；平均包围框中点的相同比例仅 34%、33%。该现象是当前居中裁剪数据的经验特征。旧方法用概率图的连续质心作弱对数几率倾斜，并可同时改变前景面积。本试验从正式模型的单片预测出发，检查直接约束二值掩膜且保持面积能否增加实际 Dice。

每折仅从该折内层拟合患者计算四份非空标注质心的平均值，再取跨病例逐轴中位数并四舍五入到最近半像素。以所得中心 ±0.5 像素作为目标矩形。只有四份预测均非空、预测平均质心距该中心最远轴小于 3 像素、且当前预测超出目标矩形时尝试修正。每步在一个等级的内外一像素边界上交换一对前景与背景像素。两边分别取绝对 logit 最小的 24 个像素，按“到目标矩形的平方距离缩减量 / (1 + 两像素绝对 logit 和)”选取最佳正收益，直到无正收益、进入目标区域或用尽交换预算。确定性处理并列，每步保持该等级面积。

交换预算选项为每图块总共 0、1、2、4、8、16 次。匹配对照一是忽略代价、只最大化相同候选对的位置收益，二是已有连续质心修正，强度为 0、0.25、0.5、0.75、1。各方案只在本折内层库患者选一个参数，随后在独立检查患者评分。固定原四折划分，医学标签限 LIDC；推理输入为单片及其已有预测。保存逐病例二值掩膜和参数收据，再独立计算全体检查患者的 Dice。主要候选为按置信度加权的交换。仅当其相对正式方法的四折内层均值增量至少 +0.05 个百分点且至少三折为正，才考虑额外外层复评。记录中心范围、触发比例、像素交换数量、各级面积差和负结果。外层验收仍须在全部原始 214 位患者、1609 个图块上达到未舍入 0.910000。
