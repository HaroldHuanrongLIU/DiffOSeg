# 单切片 SAM 的连续几何增强

原四折正式偏好 Dice 为 90.4531%。在相同患者交叉拟合引导、原公开 SAM ViT-B、已训练的提示解码器、尾部四个编码模块及输出层、5000 步和批量 12 下，检验当前模型训练只见 90 度整转时是否对位置和大小改变过于敏感。匹配对照为同一折已经训练的 live-frozen 模型。先比较原折 0、1 的内层检查患者。在训练折内拟合、选参及检查患者互斥。只用现有 LIDC 医学标注，推理仅取目标切片。

奇数步沿用原流程。偶数步对每个样本独立选取视野相对边长 0.75 至 1.25、角度 ±45 度、横向翻转概率 0.5、两个方向分别 ±4 像素的中心平移。等概率均匀抽取，随机流与抽样病例和提示扰动分离。视野以原图块几何中心为起点。将已配准的 CT 与患者折外引导同时采样到新网格，预测四组连续掩膜和原始解码器 logits；逆映射回当前整转后的原生 128 像素网格，视野外使用该例已有引导。最后与原有硬标签逐像素计算相同 Dice、BCE、面积损失。避免在边界处给训练掩膜做两次软插值。对照和候选在推理时都只用原四种整转；没有在测试时选视野或读取标签。

第一步的未增强损失须匹配同机对照。检查整数平移的逆映射、斜转的有限梯度、视野外回退及随机流独立。保持原库内五个融合权重的选择规则，然后单独检查每折，与同机同初始化的 live-frozen 对照及正式方法所选的内层参照比较。门槛预定为两折选中融合均优于同机对照，且两折平均相对正式内层参照至少 +0.03 个百分点，再扩展到另两折。保存全部试验结果；此试验只判定是否值得扩展，外层计分需另行锁定。
